## A 问题是什么

给定一个二进制字符串，如何判断它表示的整数是否能够被 3 整除？如果字符串很长，是否一定要先算出整个整数？

本项目从逐位更新余数出发，把余数 0、1、2 抽象成三个状态，建立有限状态机；再通过其他字符串判定问题认识有限状态机的一般结构，学习它与正则表达式的关系，以及状态消除法的基本思想。

项目分为 Basic 和 Advance 两部分。**Basic 为必做，包含原实验一至三和手工状态消除；Advance 为选做，包含自动转换程序及其他扩展。** 完成 Basic 即完成项目的必做要求。前置知识为基础字符串处理、循环、条件判断和取模运算。

## C 问题的来龙去脉与发展过程

项目最初研究二进制数的模三判定。因为除以 3 只有三种余数，程序只需记住当前余数，就可以根据下一位继续计算。这使一个具体数学问题变成了三个状态之间的转移问题。

进一步把状态集合、输入符号、初始状态、转移规则和接受状态提取出来，就得到了有限状态机的一般模型。更换状态的含义和转移表，同一个模拟过程就能用于其他字符串规则。

正则表达式则从另一个角度描述允许出现的字符串：连续路径对应连接，不同路径对应选择，重复循环对应星号。状态消除法把这些路径关系逐步合并，最终将状态机表示成正则表达式。Basic 通过手工案例理解这种关系，Advance 可进一步把转换过程写成程序。

本项目希望学生理解从具体问题发现规律，再把规律抽象成通用模型和自动化方法的过程。
