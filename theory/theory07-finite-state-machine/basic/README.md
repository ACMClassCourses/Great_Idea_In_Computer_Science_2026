## 1 实验一：二进制模三判定器

输入一个二进制字符串，判断它表示的整数是否能够被 3 整除，输出 `YES` 或 `NO`。例如 `110` 表示十进制 6，应输出 `YES`；`10` 表示十进制 2，应输出 `NO`。

当前余数为 `r`、下一位为 `b` 时，新余数为：

```text
new_r = (2 * r + b) % 3
```

分别用 q0、q1、q2 表示余数 0、1、2，初始状态和唯一接受状态都是 q0。

| 当前状态 | 输入 0 | 输入 1 |
| --- | --- | --- |
| q0 | q0 | q1 |
| q1 | q2 | q0 |
| q2 | q1 | q2 |

需要完成：

- 解释余数更新公式，并说明为什么只记住余数就足够。
- 画出状态图或整理状态表。
- 编写逐位更新余数的模三判定程序，不要先把整个字符串转换成整数。
- 自测 `0`、`11`、`110`、`1001` 等可整除输入，以及不可整除输入。

本实验的独立判定程序由学生自行编写，不另提供框架。通用模拟器完成后，也应能通过输入上面的转移表复现模三判定。

## 2 实验二：设计另一个简单状态机

设计一个模三之外的状态机并实现模拟。推荐任务：判断二进制字符串是否以 `01` 结尾。

需要自行确定：

- 每个状态表示什么信息；
- 初始状态和接受状态；
- 每个状态读到 `0` 或 `1` 后的转移；
- 最终根据哪个状态判断是否接受。

对推荐任务，`10101`、`11001` 应被接受，`11100` 应被拒绝。还需要检查空串、单字符和恰好为 `01` 的输入。

可以单独编写模拟程序，也可以把自己设计的完整转移表作为下节通用 DFA 模拟器的输入；需要保留状态设计说明和可复现的输入数据。

## 3 编程验收：通用 DFA 模拟器

在 [src/dfa_sim.py](src/dfa_sim.py) 中补全两个 TODO：

| 函数 | 需要实现的行为 |
| --- | --- |
| `build_dfa(n, start, accept_list, trans_rows)` | 将解析好的状态机信息组织成自己选择的数据结构，并返回给 `simulate` |
| `simulate(dfa, word)` | 从初始状态出发逐字符执行转移，最终处于接受状态时返回 `True`，否则返回 `False` |

`main()` 和输入输出已经提供，保持它们的输入输出约定。状态机的字母表固定为 `{0, 1}`，转移表完整，每个状态都有读入 `0` 和 `1` 的后继。程序需要处理输入给出的任意合法状态机；模三机和“以 01 结尾”机是其中的具体案例。

### 输入格式

| 行 | 内容 |
| --- | --- |
| 第 1 行 | `n s k`：状态数、初始状态编号、接受状态数；状态编号为 `0` 到 `n-1` |
| 第 2 行 | `k` 个接受状态编号；当 `k = 0` 时，这一行为空行 |
| 接下来 `n` 行 | 按状态 `0` 到 `n-1` 的顺序，每行 `z o`，分别表示读入 `0`、`1` 后转到的状态 |
| 接下来 1 行 | 查询字符串数量 `q` |
| 接下来 `q` 行 | 每行一个二进制字符串；空行代表空串 |

### 输出格式与数据范围

每个查询恰好输出一行 `YES` 或 `NO`，按输入顺序输出。OJ 使用全文精确比较，程序运行时不要额外输出提示或调试信息。

```text
1 <= n <= 1000
0 <= s < n
0 <= k <= n
1 <= q <= 100000
0 <= 单个查询串长度 <= 10^6
所有查询串长度之和 <= 2 * 10^6
```

## 4 实验三：手工将状态机转换为正则表达式

理解基础语法：`*` 表示重复 0 次或多次，`|` 表示选择，`()` 用于分组，`[]` 表示字符集合。说明连续转移、多条路径和循环怎样对应正则表达式的连接、选择和重复。

例如，以下状态机以 q0 为初始状态、q2 为接受状态：

```text
q0 --a--> q1
q1 --b--> q1
q1 --c--> q2
```

消除 q1 时，进入它需要读 `a`，在其中可以循环读任意多个 `b`，离开它需要读 `c`，因此合并后的表达式是 `ab*c`。

需要完成一个简单状态机的手工转换案例，可以使用上例，并写清或展示：

1. 初始状态、接受状态和转移关系。
2. 消除哪个中间状态，以及如何进入、循环和离开它。
3. 消除后怎样合并路径；存在多条可选路径时如何使用 `|`。
4. 最终的正则表达式，以及若干被接受和被拒绝的字符串。
5. 为什么转换前后的状态机和表达式描述相同的字符串集合。

可以使用正则表达式工具辅助验证，检查时需要匹配完整字符串。本实验不要求编写自动转换程序。
