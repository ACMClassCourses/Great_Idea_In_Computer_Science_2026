# RSA：Basic — 为什么公钥可以公开

## 项目介绍

传统加密要求双方预先共享秘密；RSA 则允许接收者公开一把“加密钥匙”，让任何人发送消息，而保留自己的解密秘密。它把素数、模运算和算法效率连接起来，是公钥密码学中的经典例子。

本阶段重点是理解与手算，**不要求编写完整 RSA 程序**。建议安排 **1 周，约 10–20 小时**。需要知道整数、素数和余数；最大公因数、模逆和 Euler 定理可随项目学习。

完成后，你应能解释密钥生成与加解密，区分“合法运算能还原消息”与“攻击者难以恢复消息”。

## 简要算法介绍

模运算把整数按除以 n 的余数分类，`a ≡ b (mod n)` 表示它们相差 n 的整数倍。“模逆”不是普通除法：d 是 e 模某个模数的逆，意味着它们的乘积在该模数下余 1。`gcd(a,b)` 是最大公因数；它为 1 时称 a、b 互素。`φ(n)` 统计从 1 到 n 中与 n 互素的整数个数。

RSA 的流程：

| 步骤 | 操作 | 含义 |
| --- | --- | --- |
| 选择素数 | 不同素数 p、q | 保密 |
| 计算模数 | `n=pq`，`φ(n)=(p−1)(q−1)` | n 可以公开；φ(n) 是 Euler 函数值 |
| 选择指数 | `gcd(e,φ(n))=1` | 保证 e 的模逆存在 |
| 求私钥指数 | `ed≡1 (mod φ(n))` | 求得 d |
| 加密 | `c=m^e mod n` | 使用公钥 (n,e) |
| 解密 | `m=c^d mod n` | 使用秘密 d |

消息必须先表示为 `0≤m<n` 的整数，本阶段仅操作这种整数，不讨论把长文本直接塞进公式。实际私钥还常保存 p、q 等加速信息，它们也必须保密。

### 为什么可以还原

若 m 与 n 互素，Euler 定理给出 `m^φ(n)≡1 (mod n)`。由于 `ed=1+tφ(n)`，有 `m^ed≡m (mod n)`。

这一论证不能直接覆盖不互素的消息。对一般消息，需要分别模 p 和 q，结合 Fermat 小定理与中国剩余定理；Basic 要指出这一步的必要性，完整证明放到 Advance。

## 三项任务

### Q1：公钥和私钥怎样产生？

写出密钥生成流程，解释互素条件和模逆，明确哪些量公开、哪些量保密。使用下面的手算样例：

```text
p = 61，q = 53
n = 3233，φ(n) = 3120
e = 17，d = 2753
m = 65，c = 2790
```

核对乘积、互素条件和 `17×2753 = 1 + 15×3120`。不要只抄最终数字。

### Q2：为什么加密后能解密？

记录 `65^17 mod 3233` 和 `2790^2753 mod 3233` 的计算过程。可用反复平方，只保留每一步余数，不必展开巨大整数：

```text
17 = 16 + 1
先算 65^2、65^4、65^8、65^16 对 3233 的余数，
再把所需余数相乘并取模。
```

说明互素情形的正确性，并指出一般情形还需模 p、q 讨论。计算器或 Python 可作核验，但提交要体现你的推演。

### Q3：正确性证明是否说明 RSA 安全？

写一段简短说明，包含：

- 正确性说明合法密钥和运算能还原，不代表攻击者无法恢复消息。
- 如果知道 n 的分解，可求 φ(n) 和 d；但不能直接宣称“RSA 求逆与分解已被证明等价”。
- 原始 RSA 是确定性的：同一消息得到同一密文，不能直接作为现代安全加密方案。
- 数字签名验证来源和完整性，与保密目标不同，不能简单解释为“用私钥加密明文”。

这些小参数很容易分解，只用于学习，不能用来保护真实数据。

## 算法发展历程

| 时间 | 发展 | 解决或提出的问题 |
| --- | --- | --- |
| 公钥密码以前 | 对称加密 | 双方需要预先共享密钥，密钥分发成为困难 |
| 1976 年 | Diffie 与 Hellman 公开公钥密码思想和密钥协商 | 能否在公开信道建立秘密？密钥协商与消息加密的目标不同 |
| 1977 年提出，1978 年发表 | Rivest、Shamir、Adleman 的 RSA | 用公开模幂与秘密信息构造加密和签名原语 |
| 后续 | OAEP、PSS 等编码方案与标准 | 在数学原语外加入随机性和精确的安全规则 |

后来的量子算法又改变了对“计算困难”的判断。RSA 的意义不只是两条公式，还包括数论与安全定义之间的联系。真实系统必须采用成熟的密码方案和实现。
