# RSA：Advance — 从数学构造到密码方案

## 项目介绍

Basic 展示了 RSA 能还原整数，但“可逆”距离“保护消息”还有多远？Advance 要求你实现高效模运算，补全任意消息的正确性证明，并用实验解释原始 RSA 的确定性和代数结构。随后使用成熟库了解 RSA-OAEP 加密和 RSA-PSS 签名，区分数学、方案和实现三个层次。

先修要求：完成 [Basic](../basic/README.md)，会使用 Python 函数、整数运算和基本测试。建议 **Basic 后追加 6 周，总计 7 周**。核心教学运算自行实现；标准密码方案使用库，不要求自行实现完整 OAEP/PSS。

## 简要算法介绍

### 平方–乘模幂

直接算 `m^e` 会产生巨大整数。平方–乘按指数的二进制位进行平方和乘法，每步取模，所需模乘次数与指数位数成正比：

```text
result = 1，base = a mod n
当 exponent > 0：
    若 exponent 为奇数：result = result × base mod n
    base = base × base mod n
    exponent = exponent // 2
返回 result
```

这说的是模乘次数；大整数的一次模乘也有计算成本。测试时可与 Python 的 `pow(a,e,n)` 对照，自己的核心实现不能直接用它代替。

### 模逆与密钥

扩展 Euclid 求得 `ae + bφ(n) = gcd(e,φ(n))`。当 gcd 为 1 时，`a mod φ(n)` 就是 d。模逆不存在时应报错；不应假定任何 e 都能使用。

### 任意消息的正确性

写成 `ed=1+t(p−1)(q−1)`。分别模 p 与 q：若消息是该素数的倍数，幂运算后仍为零；否则用 Fermat 小定理。两边都与原消息同余，再用中国剩余定理得到模 n 的还原。请特别解释为什么不能对所有消息直接套 Euler 定理。

### A3：分解实验

用试除分解逐步增大的小模数，记录实际 `n.bit_length()`、试除次数与耗时。只增加到个人设备可承受的规模即可。说明参数如何生成，不要只报一个时间：位数、因子大小和试除策略都会影响结果。

这展示了规模与算法成本的关系，**不能外推真实 RSA 的破解时间**。大规模分解存在优于试除的算法；“分解能恢复私钥”也不等于所有 RSA 求逆方法都已证明必须分解。

### A4：原始 RSA 的弱点

给定两个候选整数 `m0、m1`，攻击者可以公开计算 `E(m0)、E(m1)`，与未知消息的密文比较，无需私钥就区分候选消息。

另验证：

```text
E(m1) × E(m2) mod n = E(m1×m2 mod n)
```

说明密文可按可预测的代数关系改变，这叫可塑性。演示只对未编码的原始 RSA 原语成立；不能据此把同一操作直接当作对 OAEP 的完整攻击。

### A5：标准方案

建议使用 `cryptography` 等成熟库。若选择该库，可安装：

```powershell
python -m pip install cryptography
```

| 方案 | 实验 | 要说明的问题 |
| --- | --- | --- |
| RSA-OAEP | 使用库生成测试密钥，同一字节消息加密至少两次并正确解密 | 编码引入随机性，消息长度受密钥和哈希参数限制 |
| RSA-PSS | 对消息签名、验证，再分别改动消息和签名 | 验证应失败；签名验证完整性与来源，不提供保密性 |

记录密钥位数、哈希、OAEP 的 MGF/label、PSS 的盐长等参数。对库生成的实验密钥建议使用至少 2048 位；小模数只用于 A1–A4。功能测试不是安全证明，也不能证明实现没有侧信道或随机数问题。

## 选做方向

- **CRT 加速**：分别模 p、q 做私钥运算再合并，比较成本并了解故障风险。
- **混合加密**：为什么公钥机制通常建立会话密钥，长消息交给对称认证加密？
- **素数生成**：学习 Miller–Rabin 概率素性测试，解释它与素性证明的区别，以及安全随机数在密钥生成中的作用。
- **Shor 算法**：理解阶查找怎样帮助分解；不要求实现量子电路。

## 算法发展历程

| 时间 | 发展 | 需要理解的变化 |
| --- | --- | --- |
| 1976 年 | 公钥密码与 Diffie–Hellman | 从共享秘密到公开信道上的密码机制 |
| 1977–1978 年 | RSA 提出并发表 | 模幂与秘密分解形成公开/私密运算的不对称性 |
| 1994 年 | OAEP 与 Shor 算法 | 随机化编码改进原语的使用；量子计算模型改变分解的困难性 |
| 1996 年起及后续标准 | PSS、PKCS #1 的发展 | 精确定义随机签名编码和互操作规则 |
| 今天 | 混合加密与后量子迁移 | 结合不同算法的成本，并应对未来计算模型 |

Shor 给出量子多项式时间分解算法，对 RSA 构成理论威胁；实际攻击还需要足够规模、可靠度的量子设备。这不意味着量子计算能高效解决所有 NP-complete 问题。后量子密码采用不同的数学问题与方案，也不自动等于“所有方案都已被证明安全”。

最终报告应分别回答：构造为什么正确、方案针对什么攻击模型、实现可能泄漏什么信息。正确的模幂代码不能自动排除弱随机数、错误处理或时间侧信道问题。
