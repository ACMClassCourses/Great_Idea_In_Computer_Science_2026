# 理论7：从模三余数判定到正则表达式：有限状态机的抽象与转换

## 项目简介

有限状态机是计算机科学中一种重要的计算模型。它通过有限数量的状态以及状态之间的转移规则，描述输入信息被逐步处理的过程。

本项目从一个具体问题出发：如何判断一个二进制数是否能够被 3 整除。[text](../../Finite_State_Machine_to_Regular_Expression/include)

学生首先研究二进制数字在逐位读取过程中余数的变化，并将余数 0、1、2
分别表示为三个状态，由此构建一个有限状态机。在此基础上，进一步研究有限状态机的一般形式，以及有限状态机和正则表达式之间的关系。

项目后半部分将介绍有限状态机转换为正则表达式的一种通用方法，即状态消除法。学生不需要实现完整复杂的自动转换算法，重点是通过简单案例理解状态、路径、循环和正则表达式之间的对应关系。

项目最终以 OJ 评测、简单程序和展示汇报的形式完成。

## 项目内容

### 1. 模三余数判定问题

首先研究一个简单的数学问题：

给定一个二进制字符串，判断它表示的整数是否能够被 3 整除。

例如：

```text
0
11
110
1001
```

分别对应十进制中的：

```text
0
3
6
9
```

这些数字都可以被 3 整除。

如果当前已经读取的数字除以 3 的余数为 `r`，接下来读取的二进制位为 `b`，那么新的余数可以表示为：

```text
new_r = (2 * r + b) % 3
```

由于一个整数除以 3 后只可能出现三种余数：

```text
0
1
2
```

因此只需要三个状态：

```text
q0：当前余数为 0
q1：当前余数为 1
q2：当前余数为 2
```

状态转移关系如下：

| 当前状态 | 输入 0 | 输入 1 |
| ---- | ---- | ---- |
| q0   | q0   | q1   |
| q1   | q2   | q0   |
| q2   | q1   | q2   |

初始状态为 `q0`。

如果所有输入读取完成后仍处于 `q0`，说明该二进制数字可以被 3 整除。

研究重点：

* 为什么模三问题只需要三个状态；
* 输入新的二进制位后余数如何变化；
* 状态为什么可以代替完整数字；
* 数学判定问题如何转化为状态转移问题。

阶段成果：

完成模三余数判定有限状态机。

### 2. 有限状态机的一般形式

完成模三问题后，进一步研究有限状态机的一般结构。

一个有限状态机通常包含：

* 状态集合；
* 输入符号集合；
* 初始状态；
* 状态转移规则；
* 接受状态。

在模三问题中，三个余数对应三个状态，输入符号为 `0` 和 `1`。

学生需要进一步思考：如果问题发生变化，例如判断字符串是否以某个字符结尾，或者判断某种简单输入模式，是否仍然可以使用相同的状态机方法。

研究重点：

* 状态应该如何设计；
* 什么信息需要保存在状态中；
* 如何根据当前状态和输入确定下一个状态；
* 如何从具体问题中提取出有限状态机的一般结构。

阶段成果：

完成一个模三问题之外的简单有限状态机案例。

### 3. 正则表达式

正则表达式是描述字符串模式的一种方法。

例如：

```regex
0*
```

可以表示由任意数量的 `0` 组成的字符串。

```regex
ab*
```

可以表示：

```text
a
ab
abb
abbb
```

项目只需要使用较为基础的正则表达式语法，例如：

| 符号 | 含义 |
| ---- | ---- |
| `*` | 前一个元素出现 0 次或多次 |
| `|` | 两种表达式任选其一 |
| `()` | 对表达式进行分组 |
| `[]` | 从字符集合中选择一个字符 |

学生需要理解，正则表达式和有限状态机虽然表示形式不同，但都可以用来描述字符串是否满足某种规则。

研究重点：

* 正则表达式如何描述字符串集合；
* 有限状态机如何识别字符串；
* 两种表示方式之间有什么共同点。

阶段成果：

完成几个简单正则表达式案例，并分析它们对应的状态变化。

---

### 4. 有限状态机与正则表达式

有限状态机和正则表达式可以描述同一类字符串集合。

例如，一个状态机可能要求输入：

```text
先出现一个 a
中间出现任意数量的 b
最后出现一个 c
```

对应的正则表达式可以写成：

```regex
ab*c
```

状态机更关注输入过程中状态如何发生变化，而正则表达式更关注最终允许出现什么样的字符串。

学生需要通过简单例子理解两种表示方式之间的对应关系。

研究重点：

* 连续状态转移如何对应正则表达式中的连接；
* 不同路径如何对应 `|`；
* 状态循环如何对应 `*`；
* 为什么不同形式可以描述相同的语言。

阶段成果：

完成一个简单有限状态机对应的正则表达式。

### 5. 状态消除法

当有限状态机中的状态较多时，可以通过逐步消除中间状态的方法得到正则表达式。

例如有三个状态：

```text
q0 --a--> q1
q1 --b--> q1
q1 --c--> q2
```

从 `q0` 到 `q1` 需要读取 `a`。

在 `q1` 中可以重复读取任意数量的 `b`。

从 `q1` 到 `q2` 需要读取 `c`。

因此对应的字符串形式为：

```regex
ab*c
```

在更一般的情况下，删除一个状态时，需要同时考虑：

* 如何进入该状态；
* 该状态是否存在循环；
* 如何离开该状态；
* 是否存在多条不同路径。

状态消除法就是按照这种思路不断减少状态，最终得到一个正则表达式。

研究重点：

* 状态消除的基本规则；
* 路径如何合并；
* 循环如何表示；
* 为什么这种方法能够推广到一般有限状态机。

阶段成果：

完成一个简单有限状态机的状态消除过程。

## 实操案例

### 实验一：二进制模三判定器

#### 问题描述

输入一个二进制字符串，判断它表示的整数是否能够被 3 整除。

例如：

```text
输入：
110

输出：
YES
```

二进制 `110` 对应十进制数字 6，因此可以被 3 整除。

#### 实现方法

程序只需要保存当前余数。

每读取一个新的二进制位：

```text
remainder = (remainder * 2 + bit) % 3
```

如果最终：

```text
remainder == 0
```

输出：

```text
YES
```

否则输出：

```text
NO
```

#### 实现要求

使用基础字符串遍历和条件判断完成程序。

不要求先将整个二进制字符串转换成十进制整数。

涉及知识：

* 字符串；
* 循环；
* 取模运算；
* 状态变量。

该实验为必做内容。

### 实验三：有限状态机转正则表达式


其中：


#### 实现要求

不要求编写自动转换代码。

## 问题的来龙去脉与发展过程

项目最初从二进制数字的模三判定问题出发。由于一个数字除以 3 后只有 0、1、2 三种余数，因此可以只记录当前余数，而不需要保存整个数字，由此得到一个只有三个状态的有限状态机。

进一步研究会发现，有限状态机不仅可以解决模三问题，还可以描述许多字符串判定问题。与此同时，正则表达式也能够描述这些字符串集合。

因此问题从“如何判断一个数字能否被 3 整除”，逐渐发展为“如何将一个有限状态机转换成正则表达式”。

状态消除法提供了一种通用的转换方法。项目最终希望学生理解的并不是模三这一道具体题目，而是计算机科学中从具体问题发现规律，再将规律抽象成通用方法的过程。
