# Basic：单量子比特的门、相位与测量

## 题目描述

从计算基初态 \(|0\rangle\) 出发，依次执行若干个 `H`、`X`、`Z` 门。请输出最终在计算基中测量得到 `0`、`1` 的理论概率。

本题只使用实振幅的单量子比特状态 \((a,b)\)，代表 \(a|0\rangle+b|1\rangle\)。初态是 \((1,0)\)。门的作用为：

\[
X(a,b)=(b,a),\qquad Z(a,b)=(a,-b),\qquad
H(a,b)=\left(\frac{a+b}{\sqrt2},\frac{a-b}{\sqrt2}\right).
\]

最终输出 \(P(0)=a^2\) 和 \(P(1)=b^2\)。输入保证合法且门数很小。答案按绝对误差 `1e-6` 比较。

## 输入格式

第一行一个整数 `T`，表示电路数量。随后每个电路先给出整数 `m`，再给出 `m` 个门名；门名可位于同一行或多行。`m=0` 表示没有门。

## 输出格式

对每个电路输出一行两个实数：`P(0) P(1)`。

## 样例

输入：

```text
4
0
1 H
2 H H
3 H Z H
```

输出：

```text
1 0
0.5 0.5
1 0
0 1
```

`Z` 在计算基中只改变相位，直接测量时概率不变；但在 `H Z H` 中，相对相位会通过第二个 `H` 转化为不同的测量结果。
