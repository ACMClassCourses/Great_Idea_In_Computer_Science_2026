# 量子密码学与量子计算入门

这是一个为期 **8 周** 的轻量探索项目。目标不是系统学完量子计算，而是先做出几个有趣的小实验，再从量子密钥或量子算法中选择一个方向深入。

## 课程结构

### 第一阶段：简单 Demo（前 2–3 周）

先熟悉最基本的概念和代码，不追求复杂数学：

- 量子比特、叠加、测量；
- X、Z、H、CNOT 等基本量子门；
- 量子随机数生成；
- 简单的测量统计或量子态层析。

每完成一个 Demo，留下代码、运行截图和几句自己的解释即可。

### 第二阶段：二选一（中间 3–4 周）

根据兴趣选择一个主线，不要求两条都做：

**方向 A：量子密钥分发**

- 了解 BB84 的基本流程；
- 模拟 Alice、Bob 和 Eve；
- 观察拦截重发如何提高 QBER；
- 在已有基础代码上逐步补充实验。

**方向 B：量子算法**

- 选择 Deutsch、Grover 或其他一个简单算法；
- 先理解电路，再完成经典版本与量子版本的对照；
- 在已有模拟器代码上逐步补充实验。

### 第三阶段：自由探索（最后 1–2 周）

如果还有时间，可以继续了解量子纠缠、量子隐形传态、三比特纠错码、Shor、QAOA、变分量子算法等；也可以完善前面的 Demo，整理一次失败实验，或者提出一个新的问题。

## 推荐周安排

| 周次 | 内容 |
| --- | --- |
| 第 1 周 | 量子比特、叠加、测量；跑通第一个电路 |
| 第 2 周 | 基本量子门；完成量子随机数 Demo |
| 第 3 周 | 测量统计/简单量子态层析；确定二选一方向 |
| 第 4–6 周 | 完成量子密钥或量子算法主线 |
| 第 7–8 周 | 自由探索、整理实验、轻量分享 |

每周保持一个小交付物即可：一页笔记、一段代码或一张结果图都可以。没有必要为了“进度完整”一次学习所有主题。

## 当前代码框架

`src/` 目前放置了量子密钥分发和量子算法两部分基础实现，作为项目可行性验证和后续实验的起点。后续会根据最终选择的方向，逐步整理代码、补充 Demo，并统一运行方式。

当前阶段只关注：代码能否运行、核心概念是否容易理解、是否适合继续扩展；暂不要求形成对外展示的完整工程。

## 学习氛围

- 不要求高深数学，先建立直觉再补公式。
- 可以提交半成品、负结果和仍未解决的问题。
- 分享重点是“我做了什么、看到了什么、还不确定什么”。
- 模拟结果只说明模型中的现象，不直接等同于真实量子设备的安全结论。
