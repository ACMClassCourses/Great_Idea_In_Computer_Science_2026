# 实验指南：从电路到密码影响

在 `advance/` 下运行以下命令。所有输出都使用固定种子 `20260929`，确保有限次抽样可以复现。

## 1. Basic：相位与测量

```sh
python -m quantum_crypto.basic_circuits --shots 1000 --seed 20260929
```

应观察到 `I` 与 `HH` 的理论概率为 `(1,0)`，`H` 为 `(0.5,0.5)`，`HZH` 为 `(0,1)`。后两次 `H` 中间的 `Z` 只翻转相对相位；第二个 `H` 把它转化成可见的测量差异。

记录理论概率、计数和抽样误差。1000 次有限抽样接近而不必等于理论比例；这些是伪随机数驱动的模拟样本，不是物理设备产生的随机数。

## 2. Grover：oracle、扩散与过度迭代

```sh
python -m quantum_crypto.grover_experiment --qubits 2 3 4 --target 0 --max-iterations 5 --shots 2000 --seed 20260929
```

`phase_oracle` 对标记基态的振幅乘以 -1，`diffusion` 实施 \(a_i\leftarrow2\bar a-a_i\)。一个目标时，令 \(N=2^n\)、\(\theta=\arcsin(1/\sqrt N)\)，第 \(k\) 次迭代后的总成功概率为

\[
\sin^2((2k+1)\theta).
\]

报告中画出 CSV 的 `iteration` 与 `simulated_success`/`sampled_success`。最大值之后再迭代，状态在二维子空间中继续旋转，所以成功率会下降；这正是“不要盲目多迭代”的原因。它说明的是 oracle 查询模型里的振幅放大，不等于真实机器的总时间或门成本。

## 3. `N=15,a=2`：经典阶查找演示

```sh
python -m quantum_crypto.order_demo --modulus 15 --base 2
```

此处由经典循环得到 `r=4`：\(2^4\equiv1\pmod {15}\)。于是 \(2^{r/2}=4\)，

\[
\gcd(4-1,15)=3,\qquad\gcd(4+1,15)=5.
\]

这只演示“若拿到合适的阶，如何做经典后处理”，并没有实现量子阶查找，更不表示可以分解实际 RSA 密钥。

## 4. Shor 的角色分工

真正的 Shor 流程将模幂周期编码到量子态中；量子傅里叶变换（QFT）把周期结构转为频率信息；测量产生一个有限精度的样本；经典连分数从样本估计候选分母/阶；最后用模幂验证候选并用 gcd 提取因子。某个样本可能无效，某个 `a` 也可能不满足偶阶和非 \(-1\) 条件，因此需要重试。
