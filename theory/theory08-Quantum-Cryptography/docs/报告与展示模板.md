# 报告与 presentation 模板

## 报告最低结构

1. **问题与概念区分**：回答 Q1–Q3；分别定义量子算法、QKD、PQC。
2. **Basic 电路**：画出 `I`、`H`、`HH`、`HZH`，列出状态/理论概率/1000-shot 计数，解释 `HZH`。
3. **Grover 实验**：写清 qubit 数、目标集合、oracle、diffusion、迭代数、seed 与 shots；给出成功率曲线并解释过度迭代。
4. **阶查找与 Shor**：推导 `N=15,a=2,r=4` 和 gcd；分开说明经典演示、QFT、测量、连分数、后处理。
5. **密码比较**：使用 [`PQC比较.md`](PQC比较.md) 的表，并选择 ML-KEM、ML-DSA 或 SLH-DSA 之一补充标准/论文阅读。
6. **证据标签**：每个结论注明它来自数学推导、模拟观察，还是基于困难性假设的安全分析。
7. **限制与开放问题**：至少说明模拟规模、有限抽样、查询模型与实际成本的差别。

## 8 页 presentation 建议

1. 问题：量子计算改变了哪些密码假设？
2. QKD / 量子算法 / PQC 的边界。
3. Basic 电路与干涉。
4. Grover oracle 与 diffusion。
5. Grover 曲线及过度迭代。
6. `N=15` 阶查找和 Shor 流程图。
7. RSA/DH、对称搜索与三类 PQC 方案比较。
8. 结论、限制、资料日期与开放问题。
