# 课程任务与七周 Checkpoint

## Basic：量子计算与密码概念入门（第 1 周）

完成 Q1–Q3，并用二维状态向量或模拟器比较从 \(|0\rangle\) 出发的 `I`、`H`、`HH`、`HZH`。每个电路至少抽样 1000 次，记录计数与理论概率。

| 问题 | 必须说明 |
| --- | --- |
| Q1 | 量子比特不是随机经典比特：振幅可以有相对相位，测量概率是振幅模平方。 |
| Q2 | `X` 翻转计算基、`Z` 改变相对相位、`H` 转换基，`CNOT` 是条件翻转并可制备纠缠。 |
| Q3 | QKD 用量子通信建密钥；量子算法研究计算能力；PQC 是通常运行在经典设备上的抗量子算法。 |

`HZH` 是 Basic 的关键检查：中间 `Z` 虽不改变即时测量概率，却会在第二个 `H` 后把结果变为 \(|1\rangle\)。

## 不应作出的结论

- 状态向量模拟器的墙钟时间不能证明量子加速；一般 n 比特模拟需要保存 \(2^n\) 个复振幅。
- Grover 的 \(O(\sqrt N)\) 是查询模型结果，不自动等于实际门数、能耗或总时间。
- Shor 是特定代数问题上的量子多项式算法，不证明量子计算能高效解所有 NP-complete 问题。
- PQC 的安全性依赖具体的困难性假设和参数，不是“已证明任何量子攻击都无效”。
