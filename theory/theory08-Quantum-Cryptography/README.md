# 理论8：量子密码学

## 问题是什么

量子计算改变了某些问题的求解方式，也改变了密码方案的安全边界。为什么 Shor 算法威胁 RSA 和 Diffie–Hellman，而 Grover 算法对无结构搜索只给出平方级的查询加速？面对这种变化，使用量子通信建立密钥与设计能抵抗量子攻击的经典算法，又是怎样两条不同的路线？

本项目以“量子计算与密码安全”为主线，分 Basic 与 Advance 两个阶段。Basic 只需完成第 1 周内容：量子态、基本量子门、干涉和测量，并区分量子密码、量子密钥分发与后量子密码；Advance 完成其余内容：Grover 小实验、Shor 的阶查找思路、安全假设比较与文献综述。BB84 的完整模拟由第 9 个项目承担，本项目无需重复实现。

## Basic：量子计算与密码概念入门

Basic 的核心概念包含：量子比特、振幅、归一化、干涉、测量、量子电路与安全假设。完成 Basic 时，须按 **Q1–Q3** 提交简短回答。

| 编号 | 需要回答的问题 | 回答应包含的内容 |
| --- | --- | --- |
| Q1 | 量子比特与随机经典比特有什么差别？ | 量子态用复振幅描述，测量概率为振幅模平方；相位可通过后续干涉影响结果；不能把一次测量理解为读出全部振幅 |
| Q2 | H、X、Z 与 CNOT 各有什么作用？ | X 交换计算基的零和一；Z 改变相对相位；H 转换两组基；CNOT 进行条件翻转，并可与 H 组合制备纠缠 |
| Q3 | QKD、量子算法与后量子密码分别研究什么？ | QKD 用量子通信建立密钥；量子算法研究计算能力；后量子密码是力求抵抗量子攻击、通常运行在经典设备上的算法 |

**关键区分：**
- 叠加不等于可以同时读出所有答案；量子算法需要用干涉提高目标结果的测量概率。
- 量子模拟器运行成功不等于真实设备实现了同样的规模、精度或速度。
- Shor 给出特定问题的多项式量子算法，没有证明量子计算可以高效解决所有 NP-complete 问题。
- 后量子密码的安全性仍基于具体假设与参数分析，不是已被证明任何量子攻击都不可能成功。

### Basic 电路实验

从零态开始，比较直接测量、施加一次 H 后测量、施加两次 H 后测量。再比较先后施加 H、Z、H 的结果，解释为什么中间的相位变化会影响最终输出。可用两维向量手算，也可用模拟器运行。

每个电路至少抽样 1000 次，记录计数和理论概率。提交 Q1–Q3、电路图与解释。若使用经典模拟器，输出应称为模拟测量样本，不能称为实验产生了物理量子随机数。

## Advance：量子算法如何影响密码安全

Advance 在 Basic 基础上用两个代表算法连接量子计算与密码学：Grover 展示无结构搜索的查询加速，Shor 展示利用代数结构的阶查找。

建议完成以下任务：

1. 复现基本门与测量实验，用幅度向量或电路图说明干涉过程。
2. 实现 2–4 个量子比特的 Grover 搜索，显式列出标记目标的 oracle 与扩散操作。
3. 比较不同迭代次数下的成功概率，观察过多迭代可能让概率下降；将查询次数与经典搜索作对照。
4. 用 N=15、a=2 手算阶查找与分解的联系，解释 r=4 如何给出两个非平凡因子。
5. 阅读 Shor 的量子阶查找流程，标明量子傅里叶变换、测量与经典连分数后处理各自的作用；不要求实现大整数分解电路。
6. 比较 RSA、Diffie–Hellman、对称密钥搜索、格方案与哈希签名所面临的量子威胁。
7. 选择一个后量子方向阅读标准或论文，完成研究报告与 presentation，列出已知定理、参数假设与开放问题。

### 两类量子算法与实验解释

| 算法或方法 | 利用的结构 | 理论结论 | 本项目要避免的误读 |
| --- | --- | --- | --- |
| Grover | 标记 oracle 与振幅放大 | 单一目标的无结构搜索需约 \(O(\sqrt{N})\) 次量子查询 | 查询成本不等于实际门数或总运行时间 |
| Shor | 模幂的周期与阶 | 分解和离散对数可在量子多项式时间内求解 | 用小例子演示不表示能破解实际规模密钥 |
| 经典状态向量模拟 | 显式保存量子态振幅 | 一般 n 比特态需保存 2 的 n 次方个复振幅 | 不能用经典模拟器墙钟时间证明量子加速 |
| 后量子密码 | 选择没有已知有效量子攻击的具体困难问题 | 在相应假设与参数下分析安全性 | 不等于把经典数据换成量子态传输 |

Grover 与 Shor 的结论分别来自[搜索算法论文](https://arxiv.org/abs/quant-ph/9605043)和[分解与离散对数论文](https://arxiv.org/abs/quant-ph/9508027)。比较时须分别报告查询模型、输入长度和实现成本。

### 从阶查找到分解

对与 N 互素的 a，阶 r 是使 \(a^r\equiv1\pmod N\) 成立的最小正整数。如果 r 为偶数且 \(a^{r/2}\not\equiv-1\pmod N\)，可尝试计算 \(\gcd(a^{r/2}-1,N)\) 与 \(\gcd(a^{r/2}+1,N)\) 得到非平凡因子。

在 N=15、a=2 时，r=4，两个最大公因数为 3 和 5。实际流程还要处理不合适的 a、奇数阶、无效测量与重试。若课堂实验用经典循环求得 r，应明确称作“经典阶查找演示”，不能宣称实现了完整 Shor 算法。

### 密码任务与替代方向

| 对象 | 量子影响或候选基础 | 比较时必须说明的内容 |
| --- | --- | --- |
| RSA、有限域及椭圆曲线 DH | 分解或离散对数受到 Shor 威胁 | 需要足够规模的容错量子计算资源 |
| 理想对称密钥穷举 | Grover 在查询模型中提供平方加速 | 实际门成本、并行性与具体攻击模型不能省略 |
| ML-KEM | 基于模格的密钥封装 | 用于建立共享密钥，不是数字签名 |
| ML-DSA | 基于模格的数字签名 | 用于签名与验证，不用于直接保密通信 |
| SLH-DSA | 基于哈希的无状态数字签名 | 安全基础与格方案不同，仍需正确参数与实现 |

后三项的算法角色分别见 NIST 的 [FIPS 203](https://csrc.nist.gov/pubs/fips/203/final)、[FIPS 204](https://csrc.nist.gov/pubs/fips/204/final)和 [FIPS 205](https://csrc.nist.gov/pubs/fips/205/final)。本项目只比较定义、用途和安全基础，不要求自行实现标准算法。

## 附录：问题的来龙去脉与发展过程

**从量子物理到信息处理。**
量子态不仅能承载测量概率，还具有影响干涉的相位。量子计算把这些结构转化为可控制的电路，计算资源的比较因此需要新的模型。

**从算法突破到密码威胁。**
Shor 的工作说明分解与离散对数能被量子算法有效处理；Grover 则展示了无结构搜索的平方查询加速。两种结论针对不同结构，不能简化成“量子计算让所有密码同样失效”。

**从威胁识别到后量子设计。**
后量子密码寻求在经典设备上实现、同时抵抗已知经典与量子攻击的方法。格与哈希等方向承担不同任务，标准化也需要同时关注安全论证、参数与实现成本。

**从概念混用到分清安全来源。**
QKD 使用量子通信及后处理建立密钥，后量子方案依赖计算困难性，量子算法则改变攻击者的计算能力。把它们放进同一张图景后，才能准确讨论什么被替换、什么假设仍然存在，以及实验究竟展示了什么。
