# theory-1：TSP 的近似

## A 问题是什么

给定一组城市及两两之间的距离，如何找到一条经过每个城市恰好一次、最后回到起点的最短路线？这就是旅行商问题（TSP）。当城市数量增长时，枚举所有路线很快变得不可行。我们是否可以放弃“绝对最优”，换取高效计算，同时保证结果不会差得太多？

本项目分 Basic 与 Advance 两个阶段。Basic 只需完成第 1 周内容：理解度量 TSP、近似比与最小生成树的关系，手工完成倍树算法；Advance 完成其余内容：Christofides 算法、精确求解基准、局部搜索、实验与文献综述。重点是区分“有最坏情形保证”与“实验中表现不错”。

| 阶段 | 工作量安排 | 完成后的能力 |
| --- | --- | --- |
| Basic | 一周内约 10–20 小时 | 能定义度量 TSP、解释近似比，并说明倍树算法为什么是 2-近似 |
| Advance | 完成 Basic 后，再用六周推进（总计七周）；建议难度系数 1.1，以 project1 的 1.0 为基准 | 能解释 3/2 近似保证，对比精确算法与启发式，完成可复现实验和讲解 |

### Basic：度量 TSP 与近似算法入门

Basic 的核心概念包含：Hamilton 回路、NP-hard、三角不等式、近似比、最小生成树（MST）。完成 Basic 时，须按 **Q1–Q3** 提交简短回答。

| 编号 | 需要回答的问题 | 回答应包含的内容 |
| --- | --- | --- |
| Q1 | TSP 要求什么？优化问题与判定问题有什么区别？ | 优化版求最短巡回路线；判定版问是否存在长度不超过给定上限的路线；前者是 NP-hard，标准判定版是 NP-complete |
| Q2 | 什么是度量 TSP？什么是近似比？ | 距离非负、对称且满足三角不等式；对最小化问题，算法输出长度至多是最优值的某个倍数，保证需覆盖所有合法实例 |
| Q3 | 为什么把 MST 的边走两遍，再跳过重复城市，可以得到 2-近似？ | 最优回路删去一条边就是生成树，因此 MST 不比最优回路长；倍树长度不超过两倍最优值；三角不等式保证捷径不增长度 |

**关键区分：**
- TSP 的优化版不能直接称为 NP-complete；NP-complete 通常用于判定问题。
- NP-hard 不表示每个实例都难，也不表示已经证明不存在多项式精确算法。
- 近似比是算法对一类输入的保证；某次实验的误差只是该实例的测量结果。
- 一般 TSP 不满足三角不等式，不能直接使用度量 TSP 的近似保证。

### 方法与保证

| 方法 | 核心思想 | 能提供的保证 | 项目中的用途 |
| --- | --- | --- | --- |
| Held–Karp 动态规划 | 用已访问集合与终点表示子问题 | 精确最优；时间为 \(O(n^2 2^n)\) | 小规模对照基准 |
| 倍树算法 | MST 加倍后走欧拉回路，再取捷径 | 度量 TSP 的 2-近似 | 理解下界与构造法 |
| Christofides | 用奇度点最小权完美匹配替代全部加倍 | 对称度量 TSP 的 3/2-近似 | Advance 的理论主线 |
| 2-opt | 删除两条边并重连，反转一段路线 | 严格改进时不会变差；不自动获得固定常数近似保证 | 研究局部最优与工程效果 |
| LP 松弛与分支割平面 | 用松弛求下界，以搜索处理整数约束 | 松弛给下界；完整搜索可求最优 | Bonus 阅读方向 |

### 3/2 近似的证明骨架

设最优路线长度为 \(\mathrm{OPT}\)，MST 为 \(T\)，其奇度顶点集上的最小权完美匹配为 \(M\)。奇度顶点数一定为偶数。

- 从最优回路删去一条边，得到生成树，所以 \(w(T)\leq\mathrm{OPT}\)。
- 沿最优回路顺序连接奇度顶点，通过捷径得到长度不超过最优值的环；环上交替取边形成两个完美匹配，其中较轻者至多为最优值的一半。
- 因而 \(w(M)\leq\mathrm{OPT}/2\)。合并后的连通多重图各点度数均为偶数，可以走欧拉回路。
- 再次使用捷径，得到 \(w(C)\leq w(T)+w(M)\leq 3\mathrm{OPT}/2\)。

说明为什么“随便找一个匹配”会破坏上述证明。如果只接受改进的 2-opt 操作，从 Christofides 结果出发仍保留原有的 3/2 上界。

## 附录：问题的来龙去脉与发展过程

**从找最短路线到认识计算困难。**  
物流、钻孔与线路设计都能产生旅行商模型。TSP 的价值不只在于应用广泛，还在于它迫使我们区分“答案能验证”和“答案能高效找到”。动态规划减少了重复计算，却没有消除指数增长。

**从精确求解到可证明近似。**  
MST 为最优巡回路线提供可计算的下界。倍树算法把这个下界转成可行路线，展示了近似算法的基本套路：先找便宜的结构，再控制修补成本。Christofides 算法进一步利用奇度顶点，把修补开销限制在最优值的一半以内。

**从理论上界到实际求解。**  
局部搜索在许多实例上很有效，但局部最优不等于全局最优。工业求解还会结合松弛、割平面和分支搜索；评价方法时，需要同时讨论计算成本、可行性、质量证据与输入结构。

**从理论上界到实际求解。**  
局部搜索在许多实例上很有效，但局部最优不等于全局最优。工业求解还会结合松弛、割平面和分支搜索；评价方法时，需要同时讨论计算成本、可行性、质量证据与输入结构。

**从经典结果到持续改进。**  
3/2 界是理解度量 TSP 的经典起点，并非不可改进的极限。Karlin、Klein、Oveis Gharan 于 2020 年提出略优于 3/2 的随机化算法，随后又给出去随机化结果；理论进步与易于实现的教学算法各有价值。参见[随机化论文](https://arxiv.org/abs/2007-01409)与[去随机化论文](https://arxiv.org/abs/2212.06296)。
