## 一、TSP 问题与度量 TSP 的定义

给定完全图 G=(V,E)，n=|V|，边权 w(u,v)。TSP 要求找一条经过每个顶点恰好一次并回到起点的最小权 Hamilton 圈。一般 TSP 是 NP-hard，且不存在多项式近似算法（除非 P=NP）。当边权满足对称性与三角不等式（即 w(u,v)+w(v,x)≥w(u,x)）时称为**度量 TSP**，此时才有常数倍近似的可能，Christofides 的 3/2 保证正是建立在这一前提之上。

## 二、方法对比总表

| 算法 | 类型 | 核心思想 | 时间复杂度 | 空间复杂度 | 近似比 / 保证 | 适用场景 |
|---|---|---|---|---|---|---|
| Held–Karp DP | 精确 | 子集状压 DP，按"已访问集合 + 终点"做状态 | Θ(2ⁿ·n²) | Θ(2ⁿ·n) | 最优解 | n≤20~25 的小规模精确求解 |
| Christofides | 近似（理论保证） | MST + 奇度点最小完美匹配 + Euler 回路 + 捷径 | O(n³) | O(n²) | ≤ 3/2·OPT | 度量 TSP，需理论保证 |
| 2-opt / 3-opt / Or-opt | 近似（局部搜索） | 在邻域内反转子路径改善总长 | 每次 2-opt 迭代 O(n²)，3-opt O(n³) | O(n) | 无理论保证（可能远劣） | 工程实用，作 LKH 等元启发式的子例程 |
| LP 松弛 + 割平面（DFJ） | 精确（分支割平面） | 整数规划松弛为 LP，迭代添加子 Tour 消除割 | 单次 LP 多项式，整体指数但实际高效 | O(n²) | 松弛下界 + 整数最优 | 大规模精确求解（Concorde 已解 85,900 城） |

## 三、精确算法：Held–Karp 动态规划

### 状态定义

将城市编号为 1,2,…,n，固定 1 为起点。对任意子集 S⊆{2,…,n} 与终点 e∉S，定义

g(S,e) = 从 1 出发、经过 S 中所有城市各一次、最终到达 e 的最短路径长度。

### 状态转移方程

若 S={s₁,…,s_k}，记 Sᵢ = S\{sᵢ}，则最优子结构给出

$$g(S,e) = \min_{1\le i\le k}\bigl\{\,g(S_i,\,s_i) + d(s_i,e)\,\bigr\}$$

直觉是：从 1 经过 S 到 e 的最短路径，其倒数第二个城市必为某个 sᵢ∈S；去掉最后一条边后，前缀必是从 1 经过 S\{sᵢ} 到 sᵢ 的最短路径——这正是子问题最优性。边界条件 g(∅,e)=d(1,e)。

### 求解与回溯

按 |S|=0,1,2,…,n−1 的顺序填表。最终答案为

$$\min_{2\le i\le n}\bigl\{\,g(\{2,\dots,n\}\setminus\{i\},\,i) + d(i,1)\,\bigr\}$$

为还原路径，需对每个 g(S,e) 记录取得最小值的 sᵢ 作为前驱。

### 伪代码

```
HeldKarp(d, n):                         # d: n×n 距离矩阵
  for e in 2..n:
      g[{e}, e] = d[1][e]               # 边界 |S|=1
      parent[{e}, e] = 1
  for k = 2..n-1:                       # 子集大小
      for each S ⊆ {2..n}, |S| == k:
          for e in {2..n} \ S:
              g[S, e] = min over s in S of (g[S\{s}, s] + d[s][e])
              parent[S, e] = argmin ...
  best = min over i in 2..n of (g[{2..n}\{i}, i] + d[i][1])
  return best, 回溯 parent 得到路径
```

### 复杂度与适用边界

状态数为 (n−1)·2ⁿ⁻¹，每个状态转移需 O(|S|)≤O(n)，故**时间 Θ(2ⁿ·n²)、空间 Θ(2ⁿ·n)**。相比暴力枚举 n! 条排列，DP 把指数从阶乘降到 2ⁿ，已是精确解的下界突破；但 2ⁿ 仍意味着 n≈25 时状态量已破 3 千万，实际可解规模通常在 n≤20~25。空间是更紧的瓶颈，工程实现常用位运算压缩集合 + 滚动数组按 |S| 分层。

## 四、近似算法一：Christofides 算法

### 算法流程

输入为度量 TSP 实例（满足三角不等式）：

1. 求 G 的一棵**最小生成树** T；
2. 设 O 为 T 中度数为奇的顶点集（由握手定理，|O| 为偶数）；
3. 在 O 导出子图中求**最小权完美匹配** M；
4. 合并 H = T ∪ M，得连通且所有顶点度数为偶数的**欧拉多重图**；
5. 在 H 中求一条**欧拉回路**；
6. 对欧拉回路做**捷径**（shortcutting）：跳过已访问顶点，得到 Hamilton 圈。

### 3/2 近似比的证明思路

设最优 TSP 圈为 C，w(C)=OPT：

- **MST 界**：从 C 中删去任一边得到一棵生成树，故 w(T)≤OPT。
- **匹配界**：将 C 上奇度顶点按环绕 C 的顺序编号，把 C 的边划分为"奇序路径集"与"偶序路径集"两个完美匹配；两集合权值之和为 OPT，故较小者权值 ≤ OPT/2。由三角不等式，每个路径集对应 O 上一个完美匹配，其权不超过路径权之和；而 M 是最小权完美匹配，故 w(M)≤OPT/2。
- **合并与捷径**：w(H)=w(T)+w(M)≤OPT+OPT/2=3·OPT/2。H 含欧拉回路，由三角不等式知捷径不增权，故输出 ≤ 3·OPT/2。

### 复杂度与地位

瓶颈是最小权完美匹配，整体 **O(n³)**。该 3/2 比例紧（存在渐近达 3/2 的实例族），且作为度量 TSP 的最佳已知确定性近似保持了 44 年，直到 2020 年 Karlin–Klein–Oveis Gharan 才给出随机化的 (3/2−ε) 改进。

## 五、近似算法二：局部调整（邻域搜索）

### 核心思想

从一个可行圈（如最近邻或 Christofides 输出）出发，反复在其"邻域"内寻找更优解，直至邻域内无改进即达到局部最优。关键在于邻域结构的定义。

### 典型邻域

- **2-opt**：选两条不相邻边 (i,i+1) 与 (j,j+1)，删除之，按相反方向重连为 (i,j)、(i+1,j+1)，等价于反转子路径 i+1…j。每次迭代扫描 O(n²) 个候选对。
- **3-opt**：任取三条边重连，共 7 种非平凡重连方式，每次迭代 O(n³)。改进质量优于 2-opt 但代价更高。
- **Or-opt（Or-1/2/3-opt）**：取出长度为 1~3 的连续段，插入到圈中另一位置。
- **Lin–Kernighan（LK）**：动态决定 k-opt 序列长度，是变邻域搜索的集大成者，其实用化版本 LKH3 是当前最强大的启发式求解器之一。

### 复杂度与保证

2-opt 单次迭代 O(n²)，3-opt O(n³)；总迭代次数无多项式上界。**重要：局部搜索对度量 TSP 没有常数近似比保证**——已构造出 2-opt 局部最优解与 OPT 比例任意大的实例。但实证上 2-opt 通常能给出 5%~10% 的超最优解，3-opt 更优，且实现简单、易于嵌入元启发式（模拟退火、禁忌搜索、迭代 LK），是工程实践的主力。

## 六、近似算法三：线性规划松弛 + 割平面法

### DFJ 整数规划模型

对对称 TSP 引入 0/1 变量 x_e 表示边 e 是否在圈中：

$$\min\ \sum_e w_e x_e$$

$$\text{s.t.}\ \sum_{e\ni v} x_e = 2,\quad \forall v\in V\qquad\text{(度约束)}$$

$$\sum_{e\in \delta(S)} x_e \ge 2,\quad \forall\,\emptyset\ne S\subsetneq V\qquad\text{(子 Tour 消除, SEC)}$$

$$x_e\in\{0,1\}$$

度约束保证每点度数为 2；SEC 保证连通、不出现孤立小圈。子 Tour 消除约束数量为 2ⁿ⁻¹−n−1，呈指数级。

### 松弛与割平面迭代

去掉 x_e∈{0,1} 改为 0≤x_e≤1，并**先不计入 SEC**，得到 LP 松弛（本质是 2-匹配问题/最小权 2-因子）。求解后若解为整数且连通即得最优圈；否则：

1. **分离问题**：检查当前分数解是否违反某条 SEC——等价于求最小割，可用 Gomory–Hu 树或最小 s−t 割多项式解决。若存在 S 使 δ(S) 中边权之和 <2，则该 SEC 被违反，加入约束。
2. 重新求解加强后的 LP，重复直至无违反 SEC。
3. 若仍非整数，进入**分支定界**：对某分数变量 x_e 分支 x_e=0 / x_e=1，递归求解。

整个"割平面 + 分支"框架称为 **branch-and-cut**，这正是 Concorde 的核心范式。LP 松弛的下界非常紧，对许多实例松弛解本身就是整数最优；Concorde 借助大量结构化割（comb、blossom、domino parity 等）将可精确求解规模推到 **85,900 城**的世界纪录。

### 与 MTZ 模型对比

DFJ 用指数级 SEC 但 LP 界紧；MTZ（Miller–Tucker–Zemlin）引入辅助势变量 uᵢ，用 O(n²) 个多项式约束 uᵢ−uⱼ+n·xᵢⱼ≤n−1 替代 SEC，约束数多项式但 LP 界较弱，求解效率通常不及 DFJ + 割平面。
