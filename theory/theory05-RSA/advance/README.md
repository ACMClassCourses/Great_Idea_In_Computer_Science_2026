## 简要算法介绍

### 快速计算乘方后的余数：平方–乘算法

计算 `a^e mod n` 叫作“模幂运算”，即求 a 的 e 次方除以 n 的余数。直接算出完整的 `a^e` 会产生巨大整数。平方–乘算法每次乘法后就取余，因此无需保存完整的乘方结果。

下面是说明步骤的伪代码：a 为底数，`exponent` 为非负整数指数，n 为大于 1 的模数；`result` 保存当前结果，`base` 保存当前用于相乘的数，`// 2` 表示除以 2 后取整数部分：

```text
result = 1，base = a mod n
当 exponent > 0：
    若 exponent 为奇数：result = result × base mod n
    base = base × base mod n
    exponent = exponent // 2
返回 result
```

例如 `13=8+4+1`，所以 `a^13=a^8×a^4×a`。不断平方可以依次得到 a 的 2、4、8 次方的余数，再把需要的几项相乘、取余。上面的循环正是在逐项完成这件事，循环中的指数依次为 13、6、3、1，然后变为 0 并结束。

指数不断减半，所以循环次数取决于指数写成二进制时有多少位。但大整数相乘通常比小整数相乘更费时，分析耗时时也要考虑数的大小。测试时可与 Python 的 `pow(a,e,n)`（计算 a 的 e 次方对 n 的余数）对照，自己的核心实现不能直接用它代替。本文公式用 `^` 表示乘方，Python 代码中应使用 `**`。

### 模逆与密钥

Basic 的辗转相除法求最大公因数；扩展欧几里得（Euclid）算法在此基础上，还求出整数 x、y，使 `x×e + y×φ(n) = gcd(e,φ(n))`。当右边为 1 时，`y×φ(n)` 是 φ(n) 的整数倍，因此 `(x×e) mod φ(n) = 1`。把 x 转换为 `0` 到 `φ(n)−1` 之间、与它同余的数，就得到 d，即 `d = x mod φ(n)`。例如 `−367×17 + 2×3120 = 1`，而 `−367+3120=2753`，所以 d 为 2753。

请学习并实现如何在辗转相除过程中求 x、y；若最大公因数不为 1，应报告模逆不存在。可先记录每一步的除法等式，再倒着代回，观察 x、y 是怎样得到的。

### 任意消息的正确性

目标是证明对每个 `0≤m<n`，都有 `m^(ed)≡m (mod n)`，其中 `ed` 表示 `e×d`。由于 d 是 e 模 φ(n) 的逆，`ed−1` 是 φ(n) 的整数倍，因此可写成 `ed=1+t(p−1)(q−1)`，t 为非负整数。可分三步：

1. 先看除以 p 的余数。若 m 是 p 的倍数，m 和它的正整数次方余数都为 0；否则，费马（Fermat）小定理告诉我们：对素数 p，只要 m 不是 p 的倍数，就有 `m^(p−1)≡1 (mod p)`。指数关系说明 `m^(ed)=m×(m^(p−1))^(t(q−1))`，取余后相当于 `m×1`，所以仍与 m 同余。本项目可使用费马小定理，不要求证明这一定理。
2. 用同样方法证明除以 q 的余数也与 m 相同。
3. p、q 是不同素数。一个数若同时被 p 和 q 整除，就被 pq 整除。因此 `m^(ed)−m` 被 n 整除，证明完成。这是中国剩余定理在本题中用到的结论，不要求先掌握该定理的全部形式。

请说明为什么这里能包含 p 或 q 的倍数，而直接使用欧拉定理的证明不能。

### A3：分解实验

“分解”在这里指从公开的 n 找到素数因子 p、q。“试除”就是依次尝试用 2、3、4 等整数除 n，寻找能整除它的因子；只需尝试不大于 n 的平方根的整数，因为若两个因子都更大，它们的乘积就会大于 n。实现时可用 `候选因子×候选因子≤n` 判断是否继续。

自行生成几组不同小素数的乘积，从很小的 n 开始，逐步增加。记录 n 写成二进制时的位数（Python 可用 `n.bit_length()`）、试除次数与耗时，并设置尝试次数或时间上限。例如 `13` 的二进制是 `1101`，位数为 4；这里的“位”不是十进制数字的个数。若达到上限仍未找到因子，也要记录下来。无需尝试库生成的 2048 位密钥。说明如何选 p、q，因为位数相同的 n 也可能需要不同次数才能找到因子。

这展示了数据规模与计算量的关系，**不能用它推算真实 RSA 的破解时间**：大规模分解有比试除更好的算法。“分解能恢复私钥”也不能推出“任何解密方法都必须先分解”。

### A4：原始 RSA 的弱点

令 `E(m)=m^e mod n`，也就是用 E 表示加密操作。使用同一公钥，同一消息总会得到同一密文，这叫“确定性”。假设某条消息只能是 m0 或 m1，观察者就能用公钥分别计算 `E(m0)`、`E(m1)`，与收到的密文比较，判断消息是哪一个，无需私钥。请自己选一对不同的候选整数演示，候选消息都应在 `0≤m<n` 内。

另验证：

```text
E(m1) × E(m2) mod n = E(m1×m2 mod n)
```

这意味着，观察者可以把密文乘上另一个数的加密结果，让解密后的整数按相应的乘法关系变化。例如把密文乘上 `E(2)` 再对 n 取余，接收者解密后就会得到 `2×m mod n`。这种“能有规律地修改密文”的性质称为“可塑性”。请用小整数实际计算并核对。这里讨论的是直接套用乘方取余公式的 RSA；OAEP 还包含编码与检查，不能把本实验直接当作破解 OAEP 的方法。

### A5：标准方案

建议使用 `cryptography` 等成熟库。若选择该库，可安装：

```powershell
python -m pip install cryptography
```

| 方案 | 实验 | 要说明的问题 |
| --- | --- | --- |
| RSA-OAEP | 使用库生成测试密钥，用同一公钥对同一份字节数据加密至少两次，比较密文并分别解密 | 每次加入随机数据，密文通常不同，但都应还原原消息；消息长度有上限 |
| RSA-PSS | 对消息签名并验证；随后只改消息、保留原签名验证，再只改签名、保留原消息验证 | 原消息和原签名应验证通过，两种改动都应使验证失败；签名用于检查消息与私钥的对应关系，不隐藏消息 |

第一次做实验可直接采用以下设置，无需先读懂标准的全部公式：

- 使用库生成至少 2048 位的测试密钥，这里的位数指模数 n 的二进制位数。
- OAEP 的哈希与 MGF1 哈希都用 SHA-256，label 设为 `None`。
- PSS 的哈希与 MGF1 哈希都用 SHA-256，盐长设为 32 字节。

这些设置应在对应的加密与解密、签名与验证操作中保持一致。OAEP 先用很短的字节消息，如 Python 的 `b"hello"`；中文字符串可用 `.encode("utf-8")` 转换为字节。它不能直接加密任意长度的文件。

这些名称在此处的含义是：

- **哈希**把任意长度数据转换为固定长度的“摘要”，可把它理解为消息的一份简短数字指纹；消息改变时，摘要通常也改变。SHA-256 是一种哈希算法，摘要长 32 字节。摘要不能用来还原原消息。
- **MGF1**是标准规定的“掩码生成函数”，用于在编码时生成所需长度的辅助字节。此处只需知道它是 OAEP/PSS 的一个组成部分，按库接口设置即可，不要求手写。
- OAEP 的 **label** 是加解密双方约定的附加标记；本实验不使用，所以设为 `None`。
- PSS 的**盐**是签名时加入的随机字节；盐长指加入多少字节。

记录这些参数及结果即可，不要求推导标准的全部公式。A1–A4 仍用自己的小参数。即使程序能通过功能测试，也不能证明它不会因随机数可预测、运行时间泄漏秘密等问题而不安全。

## 选做方向

- **中国剩余定理加速（CRT）**：分别模 p、q 计算，再把两份余数组合成结果；比较与直接模 n 计算的耗时。不要求研究硬件故障攻击。
- **混合加密**：先用公钥方法传递一个较短的临时密钥，再用它加密长消息并检查是否被改动。为什么这样更适合文件和网络通信？
- **素数生成**：学习 Miller–Rabin 素性测试，即检查一个整数是否可能为素数的方法。它用多轮检查排除合数（大于 1 且不是素数的整数），而不是直接给出素数的完整证明；了解重复检查的作用，以及为何生成密钥要使用难以预测的随机数。
- **Shor 算法**：先选与 n 互素的整数 a，再了解“阶”是使 `a^r mod n = 1` 成立的最小正整数 r，选读找到 r 如何帮助分解 n；不要求实现量子电路。

## 算法发展历程

| 时间 | 发展 | 需要理解的变化 |
| --- | --- | --- |
| 1976 年 | 公钥密码与 Diffie–Hellman | 研究双方怎样通过公开交换信息建立秘密，而不必提前共享同一把密钥 |
| 1977–1978 年 | RSA 提出并发表 | 公开乘方取余的参数，保留解密所需的秘密 |
| 1994 年 | OAEP 与 Shor 算法 | OAEP 在加密前加入随机处理；Shor 展示了量子算法分解整数的可能性 |
| 1996 年起及后续标准 | PSS、PKCS #1 的发展 | 规定签名时怎样加入随机数据，让不同软件能够生成、检查相同格式 |
| 今天 | 混合加密与后量子密码研究 | 组合公钥和对称方法，并寻找能抵抗已知量子攻击的方法 |

Shor 证明，量子计算机在理论上可以高效分解整数，因此对 RSA 构成威胁；实际攻击仍需要足够大且能可靠运行的量子设备。必做阅读只需说明这一威胁和实际设备的限制，不要求掌握量子电路或计算复杂性分类。后量子密码研究采用其他数学问题，以抵抗已知的量子攻击；它们同样需要持续分析，不能仅凭名称就断言安全。

最终报告分别回答三个问题：公式为什么能还原？当观察者能看到公钥和密文、能自行加密候选消息时，原始 RSA 会暴露什么？程序本身还可能泄漏什么？例如，公式正确并不能防止别人猜到所用的随机数，或从运算耗时差异推测秘密。这类借助耗时等额外信息获取秘密的方法叫“侧信道攻击”，本项目只需了解含义，不要求实现攻击。
