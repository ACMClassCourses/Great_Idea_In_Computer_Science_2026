# 第一章 停机问题的提出

## 1.1 从 Collatz 猜想谈起

先观察一段简单的程序：

```python
def f(n):
    while n != 1:
        if n % 2 == 0:
            n = n // 2
        else:
            n = 3 * n + 1
    return True
```

该程序的规则如下：

- 如果 \(n\) 是偶数，则除以 2；
- 如果 \(n\) 是奇数，则乘以 3 再加 1；
- 重复上述过程，直到 \(n = 1\)。

例如，从 6 开始，序列为：

6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1

程序最终停机。

从 7 开始，序列会经过较长的过程，但最终也会到达 1。

Collatz 猜想断言：对任意正整数 \(n\)，该程序最终都会停机。该猜想至今未被证明，也未找到反例。这一现象说明，某些程序的终止性并不是显然可判断的。即使程序很短，其行为也可能极其复杂。

更重要的是，无穷多个输入无法通过逐个测试来穷尽。有限次实验不能证明对所有输入都成立。

## 1.2 停机问题的定义

由此引出停机问题：

> 给定任意程序 \(P\) 和输入 \(x\)，判断 \(P\) 在 \(x\) 上是否会停机。

形式化地说，停机问题要求判定是否存在一个程序 \(H(P, x)\)，满足以下条件：

- 如果 \(P(x)\) 会停机，则 \(H(P, x)\) 输出“会停”；
- 如果 \(P(x)\) 不会停机，则 \(H(P, x)\) 输出“不会停”。

并且要求 \(H\) 对任意程序和任意输入都能在有限步内给出正确答案。

一种自然的想法是直接模拟 \(P\) 在 \(x\) 上的运行。如果 \(P(x)\) 停机，则模拟结束，可以回答“会停”。如果 \(P(x)\) 不停机，则模拟永远不会结束，无法回答“不会停”。因此，直接模拟不能作为停机问题的判定方法。

停机问题的核心在于：是否存在比直接模拟更聪明的方法。后续章节将证明，这样的方法不存在。

# 第二章 图灵机与可计算性

## 2.1 图灵机的直观理解

为了精确讨论“什么可计算”，需要引入计算模型。最著名的模型是图灵机。图灵机可以由以下部分直观理解：

| 图灵机部件 | 生活类比 |
|---|---|
| 无限长的纸带 | 无限长的草稿纸 |
| 读写头 | 一支能读能写的笔 |
| 状态寄存器 | 当前步骤编号 |
| 转移规则 | 一本“看到什么就做什么”的手册 |

图灵机每次执行以下动作：

1. 读写头读取当前格子中的符号；
2. 根据当前状态和读到的符号查找转移规则；
3. 写入一个新符号；
4. 向左或向右移动一格；
5. 切换到新状态；
6. 重复上述过程，直到进入停机状态。

图灵机没有魔法，它只是按照规则一步一步执行。

## 2.2 图灵机的五个基本要素

简化地说，图灵机包含：

1. 一条无限长的纸带，分成格子；
2. 一个读写头，每次查看一个格子；
3. 有限个状态；
4. 转移规则：当前状态与当前符号决定写入内容、移动方向和下一状态；
5. 初始状态与停机状态。

## 2.3 示例：二进制加 1

纸带初始内容为：

`1 0 1 1 _ _ ...`

该串表示二进制 1011，即十进制 11。目标是加 1 得到 1100，即十进制 12。

简化转移规则如下：

| 当前状态 | 读到的符号 | 写入 | 移动 | 下一状态 |
|---|---|---|---|---|
| q0 | 0 | 0 | 右 | q0 |
| q0 | 1 | 1 | 右 | q0 |
| q0 | _ | _ | 左 | q1 |
| q1 | 1 | 0 | 左 | q1 |
| q1 | 0 | 1 | 左 | qf |
| q1 | _ | 1 | 右 | qf |

通过手动模拟，可以体会“机械计算”的含义。图灵机的每一步都完全由规则决定，不依赖直觉或创造性。

## 2.4 可计算、不可计算与可识别

在可计算理论中，以下区分十分重要：

- **可计算问题**：存在一台图灵机，对所有输入都能在有限步内给出正确答案。
- **不可计算问题**：不存在这样的图灵机。
- **可识别问题**：存在图灵机，在答案为“是”时停机接受；如果答案为“否”，则可能永远运行。

停机问题是“可识别但不可判定”的典型例子。对于给定的 \(P\) 和 \(x\)，可以模拟 \(P(x)\)。如果它停机，则接受；如果它不停机，则模拟永远不会停止，因此无法给出“否”的答案。

## 2.5 丘奇-图灵论题

丘奇-图灵论题指出：任何“有效可计算”的函数，都可以用图灵机计算。换言之，图灵机抓住了“计算”的本质。现代计算机能计算的问题，图灵机都能计算；图灵机不能计算的问题，现代计算机也不能计算。该论题不是数学定理，而是对“可计算”概念的普遍接受的形式化刻画。

## 2.6 通用图灵机

图灵机不仅可以计算具体函数，还可以模拟其他图灵机。存在一种特殊的图灵机，称为**通用图灵机**。它的输入是：

- 一台图灵机 \(M\) 的编码；
- 一个输入串 \(w\)。

通用图灵机模拟 \(M\) 在 \(w\) 上的运行。如果 \(M\) 在 \(w\) 上停机，则通用图灵机也停机；如果 \(M\) 在 \(w\) 上不停机，则通用图灵机也不停机。

通用图灵机的存在是计算理论中的关键事实。它说明“程序可以作为数据被处理”。现代计算机中，源代码、编译后的程序和输入数据都可以表示为二进制串，本质上就是这一思想的工程实现。

通用图灵机也为停机问题的形式化提供了基础。将图灵机 \(M\) 编码为字符串 \(\langle M \rangle\)，将输入 \(w\) 编码为字符串，则停机集可以定义为：

\[
K = \{\langle M, w \rangle \mid M \text{ 在 } w \text{ 上停机}\}
\]

后续章节将说明，\(K\) 是递归可列集，但不是递归集。

# 第三章 递归集与递归可列集

本章介绍可计算理论中两个核心概念：递归集与递归可列集。它们分别对应“可判定”与“可识别”的集合。理解这两个概念，有助于更精确地描述停机问题在不可判定性层级中的位置。

## 3.1 集合、语言与判定问题

在计算理论中，问题通常可以转化为集合或语言的成员资格问题。

设 \(\Sigma\) 是一个有限字母表，\(\Sigma^*\) 表示所有由 \(\Sigma\) 中符号组成的有限字符串的集合。一个**语言**是 \(\Sigma^*\) 的一个子集。

例如：

- 所有偶数的二进制表示构成一个语言；
- 所有语法正确的 Python 程序构成一个语言；
- 所有会停机的程序—输入对构成一个语言。

判定问题可以表述为：给定字符串 \(w\)，判断 \(w\) 是否属于语言 \(L\)。

## 3.2 特征函数与半特征函数

对于集合 \(A\)，定义其特征函数：

\[
\chi_A(w) =
\begin{cases}
1, & w \in A \\
0, & w \notin A
\end{cases}
\]

如果 \(\chi_A\) 是全可计算函数，则称 \(A\) 是**递归集**，也称**可判定集**。

对于集合 \(A\)，定义其半特征函数：

\[
\chi'_A(w) =
\begin{cases}
1, & w \in A \\
\text{无定义}, & w \notin A
\end{cases}
\]

如果 \(\chi'_A\) 是部分可计算函数，则称 \(A\) 是**递归可列集**，也称**递归可枚举集**或**可识别集**。

## 3.3 递归集

**定义**：集合 \(A \subseteq \Sigma^*\) 是递归集，当且仅当存在一台图灵机 \(M\)，对任意输入 \(w\)，\(M\) 都在有限步内停机，并且：

- 如果 \(w \in A\)，则 \(M\) 接受 \(w\)；
- 如果 \(w \notin A\)，则 \(M\) 拒绝 \(w\)。

等价地说，\(A\) 是递归集当且仅当其特征函数 \(\chi_A\) 是全可计算函数。

**例子**：

- 所有偶数的集合是递归集；
- 所有素数的集合是递归集；
- 所有语法正确的程序集合是递归集；
- 所有有限集合都是递归集；
- 正则语言都是递归集；
- 上下文无关语言都是递归集。

**闭包性质**：

递归集对以下运算封闭：

| 运算 | 是否封闭 |
|---|---|
| 并集 | 是 |
| 交集 | 是 |
| 补集 | 是 |
| 差集 | 是 |
| 连接 | 是 |
| Kleene 星 | 是 |
| 同态 | 是 |
| 逆同态 | 是 |

递归集对补集封闭，是它与递归可列集的重要区别。

## 3.4 递归可列集

**定义**：集合 \(A \subseteq \Sigma^*\) 是递归可列集，当且仅当存在一台图灵机 \(M\)，使得：

\[
A = L(M)
\]

其中 \(L(M)\) 表示 \(M\) 接受的所有字符串的集合。对于 \(w \in A\)，\(M\) 在有限步内停机并接受；对于 \(w \notin A\)，\(M\) 可能拒绝，也可能永远运行。

等价定义包括：

1. \(A\) 是某个部分可计算函数的定义域；
2. \(A = \emptyset\)，或者存在全可计算函数 \(f: \mathbb{N} \to \Sigma^*\)，使得 \(A = \{f(0), f(1), f(2), \dots\}\)；
3. 存在一台枚举器，能够输出 \(A\) 中的所有元素。

**例子**：

- 停机集 \(K\) 是递归可列集；
- 所有可满足的布尔公式集合是递归可列集；
- 所有定理集合是递归可列集；
- 所有程序在空输入上会停机的程序集合是递归可列集；
- 每个递归集都是递归可列集。

**闭包性质**：

递归可列集对以下运算封闭：

| 运算 | 是否封闭 |
|---|---|
| 并集 | 是 |
| 交集 | 是 |
| 连接 | 是 |
| Kleene 星 | 是 |
| 同态 | 是 |
| 逆同态 | 是 |
| 补集 | 否 |
| 差集 | 否 |

补集不封闭是递归可列集的关键特征。停机集 \(K\) 是递归可列集，但 \(K\) 的补集不是递归可列集。

## 3.5 枚举器与燕尾式模拟

**枚举器**是一台图灵机，它不需要输入，运行时会输出一串字符串。如果枚举器输出的所有字符串恰好构成集合 \(A\)，则称它枚举 \(A\)。允许重复输出，也允许输出顺序任意。

一个集合是递归可列集，当且仅当存在枚举器枚举它。

枚举器的工作方式通常采用**燕尾式模拟**。例如，要枚举停机集 \(K\)，可以按以下方式运行：

1. 将所有程序—输入对按某种顺序排列；
2. 对每一对，模拟有限步；
3. 如果某一对在模拟中停机，则输出该对；
4. 然后继续模拟其他对。

这种交替模拟使得即使某些计算永不停止，其他会停止的计算仍然能够被输出。燕尾式模拟是证明许多集合递归可列性的常用技术。

## 3.6 递归集与递归可列集的关系

递归集与递归可列集之间存在以下基本关系：

- 每个递归集都是递归可列集；
- 存在递归可列集不是递归集，例如停机集 \(K\)；
- 存在不是递归可列集的集合，例如 \(K\) 的补集；
- 所有语言的集合不可数，而图灵机只有可数多个，因此大多数语言既不是递归集，也不是递归可列集。

**Post 定理**：

集合 \(A\) 是递归集，当且仅当 \(A\) 和 \(A^c\) 都是递归可列集。

证明思路：

- 如果 \(A\) 是递归集，则 \(A^c\) 也是递归集，因此二者都是递归可列集。
- 如果 \(A\) 和 \(A^c\) 都是递归可列集，则分别存在半判定器 \(M_1\) 和 \(M_2\)。对于输入 \(w\)，并行模拟 \(M_1\) 和 \(M_2\)。由于 \(w\) 要么属于 \(A\)，要么属于 \(A^c\)，所以两个模拟中必有一个会接受。根据哪个接受，即可判定 \(w\) 是否属于 \(A\)。因此 \(A\) 是递归集。

Post 定理说明，停机集 \(K\) 不是递归集，因为 \(K\) 是递归可列集，而 \(K^c\) 不是递归可列集。

## 3.7 归约与完全性

**归约**是比较问题难度的重要工具。若问题 \(A\) 可以归约到问题 \(B\)，则 \(B\) 的解法可以用来解 \(A\)。因此，如果 \(B\) 是可判定的，则 \(A\) 也是可判定的；如果 \(A\) 不可判定，则 \(B\) 也不可判定。

**多一归约**：

设 \(A, B \subseteq \Sigma^*\)。若存在全可计算函数 \(f\)，使得对任意 \(w\)：

\[
w \in A \iff f(w) \in B
\]

则称 \(A\) 多一归约到 \(B\)，记作 \(A \le_m B\)。

多一归约保持以下性质：

- 若 \(A \le_m B\) 且 \(B\) 是递归集，则 \(A\) 是递归集；
- 若 \(A \le_m B\) 且 \(B\) 是递归可列集，则 \(A\) 是递归可列集；
- 若 \(A \le_m B\) 且 \(A\) 不可判定，则 \(B\) 不可判定。

**m-完全性**：

一个递归可列集 \(B\) 称为 m-完全的，如果每个递归可列集 \(A\) 都满足 \(A \le_m B\)。停机集 \(K\) 是 m-完全的。这意味着停机问题在递归可列集中具有最高难度。

## 3.8 部分递归函数、全递归函数与原始递归函数

可计算性也可以用函数而非集合来表述。

- **部分递归函数**：允许在某些输入上无定义的函数。部分递归函数类与图灵可计算函数类等价。
- **全递归函数**：对所有输入都有定义的部分递归函数。全递归函数也称一般递归函数。
- **原始递归函数**：由零函数、后继函数、投影函数，通过复合和原始递归构造得到的函数。所有原始递归函数都是全函数。

原始递归函数包括加法、乘法、幂、阶乘、斐波那契函数等。但并非所有全递归函数都是原始递归函数。阿克曼函数是一个经典反例：

\[
\begin{aligned}
A(0, n) &= n + 1 \\
A(m+1, 0) &= A(m, 1) \\
A(m+1, n+1) &= A(m, A(m+1, n))
\end{aligned}
\]

阿克曼函数是全递归函数，但不是原始递归函数。这说明“全可计算”严格强于“原始递归”。

通过加入无界最小化算子 \(\mu\)，可以从原始递归函数得到部分递归函数。无界最小化算子 \(\mu y [f(x, y) = 0]\) 表示寻找最小的 \(y\) 使 \(f(x, y) = 0\)。如果不存在这样的 \(y\)，则计算不终止。因此，部分递归函数允许无定义。

每个递归可列集都是某个部分递归函数的定义域。每个递归集都是某个全递归函数的特征函数。

## 3.9 算术层级简介

算术层级根据定义集合所需的量词交替次数对集合进行分类。

- **Σ₁ 集合**：形如 \(\exists y \, R(x, y)\) 的集合，其中 \(R\) 是递归关系。Σ₁ 集合恰好是递归可列集。
- **Π₁ 集合**：形如 \(\forall y \, R(x, y)\) 的集合，其中 \(R\) 是递归关系。Π₁ 集合恰好是补集为递归可列集的集合。
- **Δ₁ 集合**：Σ₁ ∩ Π₁。由 Post 定理，Δ₁ 集合恰好是递归集。
- **Σ₂ 集合**：形如 \(\exists y_1 \forall y_2 \, R(x, y_1, y_2)\) 的集合。
- **Π₂ 集合**：形如 \(\forall y_1 \exists y_2 \, R(x, y_1, y_2)\) 的集合。

停机集 \(K\) 是 Σ₁-完全的。\(K\) 的补集是 Π₁-完全的。算术层级向上延伸，形成越来越复杂的不可判定集合。

## 3.10 小结

递归集与递归可列集是可计算理论的基本概念。递归集对应“可判定”，递归可列集对应“可识别”。停机集是递归可列集但非递归集。递归可列集的补集不一定递归可列。Post 定理、归约、完全性、部分递归函数和算术层级提供了更精细的分析工具。

# 第四章 停机问题的不可判定性

## 4.1 反证法假设

现在证明停机问题不可判定。证明采用反证法。

假设存在一个万能程序 \(H(P, x)\)：

```python
def H(P, x):
    # 返回 True  若 P 在 x 上停机
    # 返回 False 若 P 在 x 上不停机
```

并假设 \(H\) 对所有程序和输入都能给出正确答案。

## 4.2 构造捣蛋程序 D

利用 \(H\)，构造一个程序 \(D\)：

```python
def D(P):
    if H(P, P) == True:
        while True:
            pass      # 死循环
    else:
        return        # 停机
```

程序 \(D\) 将程序 \(P\) 自身作为输入 \(P\) 传给 \(H\)。也就是说，\(D\) 询问的是：“程序 \(P\) 在输入自身时，是否会停机。”

## 4.3 分析 D(D)

现在将 \(D\) 自身作为输入传给 \(D\)，即运行 \(D(D)\)。分两种情况讨论。

**情况 1**：假设 \(H(D, D) = True\)。

这意味着 \(H\) 判定 \(D\) 在输入 \(D\) 上会停机。但根据 \(D\) 的定义，当 \(H(D, D) = True\) 时，\(D\) 会进入死循环。因此 \(D(D)\) 不停机。这与 \(H\) 的输出“会停机”矛盾。

**情况 2**：假设 \(H(D, D) = False\)。

这意味着 \(H\) 判定 \(D\) 在输入 \(D\) 上不会停机。但根据 \(D\) 的定义，当 \(H(D, D) = False\) 时，\(D\) 会立即返回。因此 \(D(D)\) 停机。这与 \(H\) 的输出“不会停机”矛盾。

两种情况下都产生矛盾。因此，假设不成立，\(H\) 不存在。停机问题不可判定。

## 4.4 对角线法直观

可以用表格表示停机问题的结构：

| 程序 \ 输入 | P1 | P2 | P3 | ... | D |
|---|---|---|---|---|---|
| P1 | 停 | 不停 | 停 | ... | ? |
| P2 | 不停 | 停 | 停 | ... | ? |
| P3 | 停 | 停 | 不停 | ... | ? |
| ... | ... | ... | ... | ... | ... |
| D | ? | ? | ? | ? | 矛盾 |

程序 \(D\) 的行为被设计为与表中对角线上的结果相反。当 \(D\) 遇到自身时，就产生了“它必须与自己相反”的矛盾。这种方法称为对角线法。

## 4.5 常见误解

| 误解 | 澄清 |
|---|---|
| “D 是恶意程序，不算正常程序。” | 可计算理论只关心程序是否合法，不关心其意图。 |
| “加一个超时限制就能判断。” | 超时只是近似，可能把运行较慢但最终会停机的程序误判为不停机。 |
| “量子计算机或更快的机器可以解决。” | 图灵可计算性与速度无关。 |
| “H 可以检测自己吗？” | 在假设中，\(H\) 是万能判定器，必须能处理包括 \(D\) 在内的所有程序。 |
| “自指是文字游戏。” | 程序可以读取自身代码，自指是合法且必然的。 |

## 4.6 证明模板

停机问题不可判定性的证明可以概括为：

1. 假设存在判定器 \(H\)。
2. 构造程序 \(D\)，使 \(D\) 在 \(H\) 说“停机”时死循环，在 \(H\) 说“不停机”时停机。
3. 分析 \(D(D)\) 的结果。
4. 若 \(H(D,D)=True\)，则 \(D\) 不停机，矛盾。
5. 若 \(H(D,D)=False\)，则 \(D\) 停机，矛盾。
6. 因此 \(H\) 不存在。

# 第五章 不可判定性的层级与更多例子

## 5.1 判定、可识别与不可识别

| 概念 | 含义 | 例子 |
|---|---|---|
| 可判定 | 存在图灵机总能在有限步内回答是或否 | 判断一个数是否为偶数 |
| 可识别 | 存在图灵机在答案为“是”时停机接受，否则可能不停 | 停机问题 |
| 不可识别 | 连“是”的情况都无法枚举 | 停机问题的补集 |

递归集对应可判定集合。递归可列集对应可识别集合。停机集 \(K\) 是递归可列集但非递归集。\(K^c\) 不是递归可列集。

## 5.2 Post 定理

Post 定理给出了递归集与递归可列集之间的精确关系：

\[
A \text{ 是递归集} \iff A \text{ 和 } A^c \text{ 都是递归可列集}
\]

该定理说明，停机集 \(K\) 不是递归集，因为 \(K\) 是递归可列集，但 \(K^c\) 不是递归可列集。

## 5.3 莱斯定理

莱斯定理指出：程序的任何非平凡语义性质都不可判定。

所谓语义性质，是指只依赖于程序所计算的函数，而不依赖于程序的具体代码形式。非平凡性质是指有些程序具有该性质，有些程序不具有该性质。

例如：

- 程序是否对所有输入都停机；
- 程序是否输出 42；
- 程序是否计算恒等函数；
- 程序是否与另一个程序等价。

这些性质都不可判定。

莱斯定理可以看作停机问题不可判定性的推广。它说明，静态分析工具不可能精确判定程序的所有非平凡语义性质。

## 5.4 其他不可判定问题

除了停机问题，计算理论中还有许多著名的不可判定问题：

- **Post 对应问题**：给定一组多米诺骨牌，判断是否存在一个序列使上下两行匹配。该问题不可判定。
- **希尔伯特第十问题**：判断一个丢番图方程是否有整数解。该问题不可判定。
- **CFG 等价性问题**：判断两个上下文无关文法是否生成相同语言。该问题不可判定。
- **矩阵可达性问题**：判断一组矩阵能否通过乘法得到特定矩阵。该问题不可判定。
- **王氏瓷砖问题**：判断一组瓷砖能否铺满整个平面。该问题不可判定。

这些不可判定问题通常通过归约到停机问题来证明。

## 5.5 图灵度简介

图灵度是衡量问题不可判定程度的工具。若问题 \(A\) 可以用问题 \(B\) 作为神谕来判定，则记作 \(A \le_T B\)。图灵度是所有等价类的集合。

- 递归集的图灵度为 \(0\)。
- 停机问题的图灵度为 \(0'\)。
- 存在无穷多个递归可列度。
- 算术层级中的集合对应更高的图灵度。

图灵度理论是可计算理论的重要分支，研究不同不可判定问题之间的相对难度。

## 5.6 对编程实践的意义

停机问题不可判定，对编程实践有深刻影响：

1. 不存在万能程序能自动检测死循环、内存泄漏和所有 bug。
2. 编译器、IDE 和静态分析工具只能做近似判断。
3. 程序验证和静态分析存在理论极限。
4. 人工智能可以辅助发现 bug，但不能绕过可计算性边界。
5. 莱斯定理说明，程序的非平凡语义性质不可判定，因此完美的程序分析工具不存在。
