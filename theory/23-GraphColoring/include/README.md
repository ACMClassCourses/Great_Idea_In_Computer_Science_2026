## 题面（可直接粘贴到 OJ 题目描述）

**题目描述**

给无向图的每个顶点分配一种颜色（颜色编号 0、1、2），要求每条边的两个端点颜色不同。请用**固定规则的朴素回溯搜索**判定给定的图能否三染色：能则输出找到的第一个合法染色方案，不能则报告无解。

为保证输出唯一，搜索规则完全固定：顶点染色顺序固定为 `0, 1, …, n-1`；每个顶点按颜色 `0, 1, 2` 的顺序尝试；只与**已染色**的邻居判冲突；找到第一个完整方案立即停止。还需要统计搜索规模：`NODES` = 进入递归函数的总次数——记 `dfs(v)` 为"给顶点 v 染色（`0..v-1` 已染好）"，则 `dfs(0)` 的首次调用计入，`v == n` 的成功终止调用也计入。

**输入格式**

```text
n m
u1 v1
u2 v2
…
um vm
```

- 顶点数 `1 ≤ n ≤ 500`，边数 `0 ≤ m ≤ n(n-1)/2`，顶点编号 `0..n-1`，无重边；
- 若输入含自环（某条边 `u == v`）：该图必然无法合法染色，直接输出 `UNSAT` 与 `NODES 0`（框架已完成此判断，不进入搜索）。

**输出格式**

- 可三染色时输出三行：第一行 `SAT`；第二行 n 个空格分隔的颜色（第 i 个为顶点 i-1 的颜色，即按顶点编号 0..n-1 的顺序）；第三行 `NODES x`；
- 不可染色时输出两行：`UNSAT`、`NODES x`。

**样例输入**（三角形）：

```text
3 3
0 1
1 2
2 0
```

**样例输出**：

```text
SAT
0 1 2
NODES 4
```

样例说明：依次进入 `dfs(0)、dfs(1)、dfs(2)、dfs(3)` 共 4 次调用；顶点 0 染 0、顶点 1 染 1、顶点 2 染 2 即成功。

**数据范围与提示**

- 语言：Python 3，仅标准库；评测为全文精确比较（注意大小写、空格与末尾换行）；
- 朴素回溯的最坏复杂度是指数级的——这正是本题想让你体会的。测试数据保证在上述固定规则下可以较快完成，但请想想：同样的图，为什么有的实例瞬间出解、有的要搜几十万节点？
- 框架的 `main()` 已完成输入解析、自环判断与输出，并把 Python 递归深度上限调高；你只需实现 `three_color(n, adj)`。

## 上传与打包说明

1. 在 OJ 后台新建题目（建议标题「图的三染色判定：朴素回溯」），语言限定 Python 3，粘贴上方题面；
2. 测试数据用「数据 (zip)」上传，**格式要求严格**（见 OJ 官方帮助页「如何创建数据包？」/ `/OnlineJudge/help/admin/data-format`）：**压缩包文件名必须是 `题号.zip`**（题号是数据库主键 id），且**包内顶层是以题号命名的文件夹**，文件放在其中：`题号.zip/题号/1.in`、…、`题号.zip/题号/config.json`（结构与 A+B 数据包 `1000.zip/1000/…` 一致）。`config.json` 缺失或路径不对会报"需要 json 文件"之类的错误。在本目录执行（把 `<ID>` 换成实际题号，**两处都要换**）：

   ```bash
   cd testcases && mkdir -p <ID> && cp *.in *.out config.json <ID>/ && zip -r ../<ID>.zip <ID> && rm -rf <ID>
   ```

   若使用「数据（GUI）」上传，则逐点上传 `.in`/`.out` 并按 `config.json` 手工建组：simple（1–5）25 分、complex（6–12）35 分、large（13–16）25 分、robust（17–19）15 分；所有测试点时限 2000 ms，内存均 256 MiB，无需 SPJ（`SPJ: 0`）；
3. 如需重新生成或调整测试点，运行 `python3 ta/include/gen_testcases.py include/testcases`（生成器用独立的显式栈实现计算答案，与递归参考答案交叉验证）。

| 编号 | 分组 | 考查点 |
| --- | --- | --- |
| 1 | simple | 三角形 K3（题面样例，SAT `0 1 2`，NODES 4，可手算） |

| 10 | complex | 4×4 网格图：二分图，SAT |
| 11 | complex | Grötzsch 图（11 点）：无三角形却需 4 色，UNSAT |
| 12 | complex | K5：UNSAT |
| 13 | large | 长链 n=200：递归深度 201，NODES 201 |
| 14 | large | 偶环 n=500（n 上限）：递归深度 501 |
| 15 | large | 完全二分图 K(40,40)：1600 条边，NODES 81 |

| 18 | robust | n=1 且自环：UNSAT，NODES 0 |

**出题备注**：朴素回溯对随机图实例的耗时极不稳定（实测 n=100 m=500 的稠密 UNSAT 实例需 3300 万节点 / 39 s，n=60 m=100 的部分实例超过 5 s），因此大点全部采用结构可证的图（链、环、二分图、分层三部图），随机图只保留实测可行的小规模实例。若需新增数据点，**必须先用 `ta/include/verify_testcases.sh` 实测耗时**。
