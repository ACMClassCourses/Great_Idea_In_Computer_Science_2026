# Basic：单层虚拟文件操作（学生起点）

本目录是 Basic 阶段下发给学生的项目起点。项目只提供构建配置、一个最小的 `main.cpp` 和全部本地测试，不限定函数划分与实现方式。

请先阅读上一级目录 `README.md` 的 Basic 部分并完成 Q1–Q5。**错误行的文字格式在本文件中固定下来**，以便本地测试自动比对。

## 已提供内容

- `src/main.cpp`：只有状态声明和 `TODO` 注释；
- `CMakeLists.txt`：CMake 构建与 ctest 测试配置；
- `tests/`：全部本地输入输出测试。

## 需要完成的内容

- 用 `std::getline` 逐行读取命令，直到 `exit` 或输入结束（EOF）；
- 用 `std::map<std::string, std::string>` 保存“文件名 → 内容”；
- 实现 `pwd`、`ls`、`touch`、`cat`、`echo`、`echo ... > 文件名`、`exit`；
- 遇到错误时输出一行 `ERROR`，然后继续处理下一条命令。

## 行为约定

- **分词**：命令与参数之间用一个或多个空格分隔，`>` 是一个独立的词。
- **合法文件名**：非空，字符只允许英文字母、数字、下划线 `_`、点 `.`、连字符 `-`；不能是 `.` 或 `..`。
- **提示符**：交互使用时可以有提示符，但读文件测试时必须关闭（不得向标准输出写任何非结果内容）。

| 命令 | 行为 |
| --- | --- |
| `pwd` | 输出 `/` |
| `ls` | 按 `std::string` 字节序（ASCII 字典序）列出文件名，每行一个；空目录不输出任何内容 |
| `touch 名` | 不存在则创建空文件；已存在则保持内容不变 |
| `cat 名` | 原样输出文件的全部内容，不额外追加换行；空文件不产生任何字符 |
| `echo [参数...]` | 参数用一个空格连接，末尾加一个换行；无参数只输出一个换行 |
| `echo [参数...] > 名` | 把 `echo` 的输出写入文件（覆盖），文件不存在则创建；**不显示**这段输出 |
| `exit` | 结束程序 |

## 错误格式

任何错误都只输出一行 `ERROR`，**不附加其他内容**，随后继续处理下一条命令。

需要输出 `ERROR` 的情况：

- 未知命令；
- 缺少参数（`touch`、`cat`）；
- 多余参数（`pwd`、`ls`、`touch`、`cat`；`echo` 接受任意多个参数，不会因参数多而报错）；
- 非法文件名；
- `cat` 的文件不存在；
- `>` 后没有文件名。

## 构建与测试

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

也可以手动运行单个样例：

```bash
./build/minishell-basic < tests/example1.in
```

初始框架可以编译，但命令尚未实现，因此测试不会通过。全部完成后应看到：

```text
100% tests passed, 0 tests failed
```

> **换行符**：`tests/*.in` 使用 CRLF 换行。请在 `std::getline` 之后去掉行尾的 `\r`，否则每行最后一个词会多出一个不可见字符。测试比对会忽略行尾换行差异，程序输出 LF 或 CRLF 都算通过。
