# Advance：路径与命令组合（学生起点）

本目录是 Advance 阶段下发给学生的项目起点。项目只提供最基本的节点概念、构建配置和全部本地测试，不限定路径解析、命令层或管道执行器的具体设计。

请先阅读上一级目录 `README.md` 的 Advance 部分（G1–G6）。**错误行的文字格式在本文件中固定下来**，以便本地测试自动比对。

## 已提供内容

- `src/main.cpp`：`NodeType`、`Node`、`Shell` 的声明与根目录初始化，以及一个最小的 `main`；
- `CMakeLists.txt`：CMake 构建与 ctest 测试配置；
- `tests/`：全部本地输入输出测试。

## 需要完成的内容

自行设计并实现：

- 路径解析：绝对路径、相对路径、`.`、`..`（根目录的父目录仍是根目录）；
- `mkdir`、`cd`、`pwd`、`ls`；
- `touch`、`cat`、`echo`、`tee`；
- `<`、`>` 重定向与多级管道；
- 组合语法检查、执行顺序和错误处理；
- 所需的类与辅助函数。

可以自由增加、删除或调整自己编写的类与私有接口，但必须保留目录树结构，并保证程序行为符合总题面。

本项目是**单文件**工程：所有代码都写在 `src/main.cpp` 里，不需要额外的头文件或源文件。提交到 OJ 的也是这一个自包含的 `.cpp`。

## 行为约定

- **分词**：只用空格分词；`|`、`<`、`>` 都是独立的词。暂不处理引号、转义、变量与通配符。
- **路径**：以 `/` 开头为绝对路径，否则相对当前目录；`.`、`..`、`/` 只表示路径含义，不是独立命令。根目录的 `..` 仍是根目录。
- **重定向限制**：`<` 只允许出现在**第一条**命令，`>` 只允许出现在**最后一条**命令，各最多一次。
- **`cd`、`exit`**：只支持独立执行，不能出现在管道中。
- **执行顺序**：先完整检查组合语法，再从左到右执行；中间结果不打印，只有最终结果才显示或被重定向。
- **输入文本**：没有上游也没有 `<` 时，输入文本为空字符串。
- **失败处理**：任何一条命令出错就单独输出一行 `ERROR` 并停止本次组合，**不把错误文本传给下游**；已成功的 `tee` 等副作用无需回滚。

| 命令 | 行为 |
| --- | --- |
| `pwd` | 输出当前目录的绝对路径（根目录为 `/`） |
| `ls [目录]` | 默认当前目录；按 `std::string` 字节序列出**直接**子条目（文件与目录同名规则一致，每行一个），不递归 |
| `mkdir 路径` | 创建目录；父目录须已存在；重名或文件/目录类型冲突时报错 |
| `cd 路径` | 只能进入已有目录 |
| `touch 文件` | 不存在则创建空文件；已存在则保持内容不变 |
| `cat [文件...]` | 多个文件按顺序连接；**没有文件参数时原样输出传入文本** |
| `echo [参数...]` | 参数用一个空格连接，末尾加一个换行（忽略传入文本） |
| `tee 文件` | 把传入文本覆盖保存到文件，同时把同一份文本作为输出返回 |
| `echo ... > 文件` | 把最终输出写入文件（覆盖）；文件不存在则创建，但不能覆盖目录 |

## 错误格式

任何错误都只输出一行 `ERROR`，**不附加其他内容**。语法错误在检查阶段输出，运行期错误在执行到该命令时输出。

需要输出 `ERROR` 的情况：

- 未知命令；
- 缺少参数、多余参数；
- 文件不存在、目录不存在；
- 需要目录却拿到文件（`cd`、`ls`、路径中间段）；
- 需要文件却拿到目录（`cat`、`touch`、`tee`、`>`）；
- `mkdir` 重名或文件、目录类型冲突；
- `<`、`>` 后没有文件名；
- 管道段为空（如 `a | | b`）；
- `<`、`>` 位置不合法或重复出现；
- `cd`、`exit` 出现在管道中。

## 构建与测试

```bash
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

也可以手动运行单个样例：

```bash
./build/minishell-advance < tests/example1.in
```

初始框架可以编译，但命令尚未实现，因此测试不会通过。全部完成后应看到：

```text
100% tests passed, 0 tests failed
```

> **换行符**：`tests/*.in` 使用 CRLF 换行。请在 `std::getline` 之后去掉行尾的 `\r`，否则每行最后一个词会多出一个不可见字符。测试比对会忽略行尾换行差异，程序输出 LF 或 CRLF 都算通过。
