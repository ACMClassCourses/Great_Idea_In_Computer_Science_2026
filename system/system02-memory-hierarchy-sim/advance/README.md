# Advance：页面置换策略比较

## 要做什么

在 Basic 的 FIFO 基础上实现 LRU 和 CLOCK。每次运行根据输入选择一种策略，输出每次访问后的命中情况和缓存内容。学习目标、阅读资料和实验要求见[项目说明](../README.md)中的 Advance 部分；程序输入输出及缓存排列方式以本文为准。

自行编写程序，不要求采用指定的文件划分、类或函数接口。不提供代码模板；标准输入输出测试数据位于 `tests/data/`。

## 输入格式

每次运行只处理一组数据，只模拟一种策略，缓存初始为空。

- 第一行是策略名称，只能为 `FIFO`、`LRU` 或 `CLOCK`，区分大小写。
- 第二行是两个整数 `c n`，分别表示缓存容量和访问次数。
- 第三行是 `n` 个页面编号，按给定顺序依次访问。

数据范围：

- `1 <= c <= 1000`。
- `1 <= n <= 100000`。
- `c × n <= 1000000`，用于限制逐步输出的总规模。
- `0 <= 页面编号 <= 2147483647`，每个页面占用一个缓存槽位。

保证输入满足以上要求，不要求为非法输入输出错误提示。

## 缓存与策略规则

缓存槽位从左到右编号为 `0` 至 `c - 1`，页面编号与槽位编号是不同的概念。

三种策略均遵守以下存放与展示规则：

1. 命中时，页面在缓存中的位置不变。
2. 未命中且缓存未满时，将页面填入最左侧的空槽位。
3. 未命中且缓存已满时，由所选策略决定淘汰对象，新页面直接放入被淘汰页面原来的槽位，其余页面不移动。
4. 缓存内容始终按槽位下标从小到大输出，只输出已占用的槽位。输出顺序不表示进入顺序或最近访问顺序。

各策略的淘汰与内部状态更新规则：

- **FIFO**：淘汰当前缓存中最早装入的页面；命中不改变进入顺序。
- **LRU**：淘汰当前缓存中距离上次访问最久的页面；每次访问（包括命中）都更新该页面的最近访问记录，但不移动页面所在槽位。
- **CLOCK**：维护每个槽位的访问位和一个循环指针。初始指针为 `0`，所有访问位为 `0`。未满时按槽位顺序填入，新页面访问位置为 `1`，指针移至装入位置的下一槽位。命中时只将对应访问位置为 `1`，指针不动。已满且未命中时，从指针处开始扫描：遇到访问位 `1`，将其清为 `0` 并前进；遇到访问位 `0`，原位替换页面，将访问位置为 `1`，指针前进一格。指针到达末尾后会回到最左侧，仍然可以继续遍历。

## 输出格式

输出恰好 `n` 行，每行对应一次访问，表示本次访问处理完成后的状态：

```text
访问结果 页面编号1 页面编号2 ...
```

- 访问结果只能为小写 `hit` 或 `miss`：访问前页面已在缓存中为 `hit`，否则为 `miss`。填充空槽位也算 `miss`。
- 后续字段为访问完成后的缓存内容，按上述槽位顺序输出。
- 每两个字段之间恰好一个半角空格，行首、行尾无空格，每行以换行结束。

## 输入输出示例

三组示例使用相同容量和访问序列，分别独立运行。

### 示例 1：FIFO

输入：

```text
FIFO
3 7
1 2 3 1 4 2 5
```

输出：

```text
miss 1
miss 1 2
miss 1 2 3
hit 1 2 3
miss 4 2 3
hit 4 2 3
miss 4 5 3
```

### 示例 2：LRU

输入：

```text
LRU
3 7
1 2 3 1 4 2 5
```

输出：

```text
miss 1
miss 1 2
miss 1 2 3
hit 1 2 3
miss 1 4 3
miss 1 4 2
miss 5 4 2
```

### 示例 3：CLOCK

输入：

```text
CLOCK
3 7
1 2 3 1 4 2 5
```

输出：

```text
miss 1
miss 1 2
miss 1 2 3
hit 1 2 3
miss 4 2 3
hit 4 2 3
miss 4 2 5
```

## 验收方式

将标准输入交给程序，运行结束后，将程序的标准输出与对应的标准输出逐行、逐字段比对。页面顺序、`hit` / `miss` 和输出格式均须符合本文要求。

测试应覆盖容量为 1、连续重复访问、所有页面均能装入、循环访问超过容量的页面、热点切换，以及 CLOCK 的命中更新、指针回绕和多槽位扫描等情况。

实验报告可以根据逐步输出自行整理命中次数、缺页次数和对比表，不要求程序额外输出这些内容。阅读笔记和讲解材料仍按项目说明中的 G1–G7 要求完成。

使用下述 `tests/run_tests.py` 和 `tests/data/` 验收，无需代码模板或 CMake。

## 运行输入输出测试

需要 Python 3 和支持 C++11 的编译器。在 `advance/` 目录运行：

```bash
python3 tests/run_tests.py main.cpp
```

脚本使用 `g++` 编译源码到临时目录，再按文件名顺序运行 `tests/data/` 下的全部 36 组数据。支持传入多个源文件；也可以直接测试已有可执行程序：

```bash
python3 tests/run_tests.py --exe ./memory-simulator
python3 tests/run_tests.py main.cpp --pattern '03_*.in'
python3 tests/run_tests.py main.cpp --timeout 10 --compiler clang++
```

每组测试显示 `[PASS]` 或 `[FAIL]`，最后汇总通过数量。全部通过时，最后一行为：

```text
36/36 passed; 0 failed.
```

若有失败，根据报告的用例名称查看 `tests/data/` 中对应的 `.in` 和 `.out`；输出不匹配时，根据首个差异的行号和片段定位问题。

输出按字节严格比对，包括空格、大小写、行尾换行和 LF 换行符。失败时报告首个不同位置、输出片段、异常退出码或超时。默认每组限时 5 秒；标准错误仅用于诊断，不参与答案比对。程序应从标准输入读取并向标准输出写入，运行时工作目录为临时目录。

全部通过时脚本退出码为 `0`；答案错误、程序异常退出或运行超时为 `1`；参数、测试数据或编译环境错误为 `2`（编译失败为 `1`）。
