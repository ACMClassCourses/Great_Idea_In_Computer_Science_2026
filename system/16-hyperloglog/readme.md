# HyperLogLog 项目

这个项目研究一个问题：

> 数据量很大时，怎样用很少的内存估计不同元素的数量？

项目周期为 8 周。

实现分成 3 个阶段：

1. `HLL0`：先把 HLL 算法写正确。
2. `DenseHLL`：把每个寄存器压缩到 6 位，并加入序列化和缓存。
3. `SparseHLL`：小数据时使用稀疏表示，达到条件后自动转为 dense。
