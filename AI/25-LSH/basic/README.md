# LSH 近似最近邻检索（基础版）

> 一句话：用局部敏感哈希（LSH）在 MNIST 数据集上找最相似的图片，单文件，需要你写 2 个核心函数。

## 这是个啥？

这个项目的核心是 **LSH（局部敏感哈希）**——一种快速找"最相似数据"的算法。

用的数据集叫 MNIST：6 万张训练图片 + 1 万张测试图片，每张 28×28 像素的手写数字。程序要做的事情：

1. 读训练图片，建 LSH 索引（把相似的图片分到同一个"桶"里）
2. 拿测试图片去查，用 LSH 快速找到候选（不用翻全部 6 万张）
3. 在候选里算距离，取最近的一张
4. 用最近的那张训练图片的标签来"猜"测试图片是几
5. 输出准确率

**LSH 的核心思想（一句话）**：把相似的图片扔进同一个"桶"里，查询时只搜这些桶，不用翻全部 6 万张。这是大公司做"以图搜图"的简化版。

**你需要写代码**：程序不是现成的，有两个核心函数留了 TODO，你得自己实现。别慌，每个都只要 4~5 行，有详细提示和参考答案。

## 你要做的任务

### TODO 1（必做）：实现距离函数

在 `lsh_basic.cpp` 里找到 `squared_distance()` 函数。

**目标**：计算两张图片的平方欧氏距离。

**公式**：`distance = (a[0]-b[0])² + (a[1]-b[1])² + ... + (a[dim-1]-b[dim-1])²`

**提示**：
1. 定义 `std::int64_t dist = 0` 用来累加
2. 用 `for` 循环遍历每一维 `d`（从 0 到 `dim-1`）
3. 算差值：`diff = std::int64_t(a[d]) - b[d]`（转 int64_t 防溢出）
4. 累加：`dist += diff * diff`
5. 返回 `dist`

**验证**：写对了准确率 95%+，没写准确率 18%（瞎猜）。

**卡住了？** 函数注释里有完整的参考答案，取消注释就能看。但建议你先自己想 5 分钟。

### TODO 2（必做）：实现多探测查询

在 `lsh_basic.cpp` 的 `query()` 函数里找到 `TODO 2`。

**目标**：当候选数太少时，去查每张表里"差 1 位"的相邻桶，把更多候选捞回来。

**提示**：
1. 外层 `for` 循环遍历每张表：`for (size_t i = 0; i < tables.size(); ++i)`
2. 内层 `for` 循环遍历每个位：`for (int bit = 0; bit < config.bits_per_table; ++bit)`
3. 相邻桶号 = `sigs[i] ^ (uint32_t(1) << bit)`（XOR 翻转第 bit 位）
4. 调用 `add_bucket(tables[i], 相邻桶号)`

**验证**：写对了准确率 95%+，没写准确率约 80%。

**卡住了？** 同样有参考答案在注释里。


### 准确率只有 18%

- 有没有 `return 0` 忘了删
- 循环里是不是用了 `a[d]` 和 `b[d]`（别写反）

### 准确率 80% 左右（不是 95%+）
