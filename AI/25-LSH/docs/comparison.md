# 基础版 vs 提高版对比

## 功能矩阵

| 功能/模块 | 原始项目 | 基础版 | 提高版 | 说明 |
|---|---|---|---|---|
| MNIST 文件读取 | 有 | 保留（同文件内） | 保留（独立模块） | 核心功能，都保留 |
| 随机超平面签名 | 有 | 保留 | 保留 | LSH 的核心 |
| 多哈希表建索引 | 有 | 保留（L=8） | 保留（L=16） | 基础版表少一些，跑得快 |
| 多探测查询 | 有 | 保留 | 保留 | 候选太少时查相邻桶 |
| 1-NN 分类 | 有 | 保留 | 保留 | 取最近邻的标签 |
| k-NN 分类 | 无 | 无 | **需实现** | 提高版的核心挑战 |
| 多数投票 | 无 | 无 | 提供（需 k-NN） | k 个邻居投票 |
| 命令行参数 | 仅数据目录 | 仅数据目录 | `-k -n --no-detail` | 提高版更灵活 |
| 计时输出 | 有 | 无 | 有 | 提高版保留计时 |
| ASCII 艺术打印 | 无 | 有 | 有 | 让输出更直观 |
| 测试用例 | 3 个 | 无 | 4 个 | 提高版有自测 |
| 保底方案 | 无 | 无 | 有（lsh_complete.cpp） | 卡住了也能交 |
| 代码结构 | 多文件 | 单文件 | 多文件 | 基础版最简单 |
| 注释量 | 中等 | 多 | 多 | 基础版注释最多 |
| TODO 任务 | 无 | 2 必做 + 2 选做 | 2 核心 + 3 选做 | 基础版也要求写代码 |

## 代码量对比

| 版本 | 文件数 | 总代码行数 | 说明 |
|---|---|---|---|
| 基础版 | 1 | ~390 行 | 全在 lsh_basic.cpp，含 2 个必做 TODO |
| 提高版 | 6 | ~600 行 | 含测试和保底方案 |
| 原始项目 | 5 | ~450 行 | 参考 |

## 参数差异

| 参数 | 基础版 | 提高版 | 原始项目 |
|---|---|---|---|
| L（表数） | 8 | 16 | 16 |
| K（位数） | 8 | 12 | 12 |
| min_candidates | 20 | 20 | 20 |
| seed | 42 | 42 | 42 |
| 默认测试数 | 1000 | 全部 | 全部 |

基础版用更少的表和更少的位，是为了跑得更快（20 秒 vs 30 秒），准确率差一点但够用。

## 适合人群

### 基础版适合

- 刚学完变量、循环、函数、数组、简单类
- 没写过多个文件的项目
- 想快速看到结果
- 对 LSH 完全不了解

### 提高版适合

- 基础版跑通了
- 会写简单类和函数
- 想学多文件项目结构
- 想自己写点算法代码
- 想体验测试驱动开发

## 挑战设计对比

### 基础版的 TODO

| TODO | 难度 | 类型 | 说明 |
|---|---|---|---|
| 实现距离函数 squared_distance | ★★ | 必做，~5 行 | 平方欧氏距离，核心公式 |
| 实现多探测查询 | ★★ | 必做，~4 行 | 候选太少时查相邻桶 |
| 调参实验 | ★★ | 选做 | 理解参数影响 |
| 跑全部测试集 | ★ | 选做 | 改一行数字 |

基础版的 2 个必做 TODO 不写程序也能跑，但准确率很低（18%），写对了 95%+。

### 提高版的挑战

| 挑战 | 难度 | 类型 | 说明 |
|---|---|---|---|
| 实现 query_knn | ★★★ | 写算法 | 核心挑战，有保底 |
| 用 k-NN 分类 | ★★ | 调用 | 验证你的实现 |
| 加命令行参数 | ★★ | 扩展 | 选做 |
| 加暴力搜索对比 | ★★ | 扩展 | 选做 |
| 加新测试 | ★★★ | 写测试 | 选做 |

提高版的挑战 1 是核心，不实现也能跑（用 1-NN），实现了功能更强。

## 从基础版到提高版的过渡

如果你先跑了基础版，再看提高版会觉得熟悉：

1. `lsh_basic.cpp` 里的 MNIST 读取 → 提高版拆成了 `mnist.h` + `mnist.cpp`
2. `lsh_basic.cpp` 里的 LshIndex 类 → 提高版拆成了 `lsh.h`（声明）+ `lsh.cpp`（实现）
3. `lsh_basic.cpp` 里的 main → 提高版的 `main.cpp`，加了参数解析和 k-NN 调用
4. `lsh_basic.cpp` 里的 `query()` → 提高版一模一样，多了个 `query_knn()` 要你写

**建议**：如果提高版看不懂，先回去看基础版的单文件版，逻辑是一样的，只是没拆开。
