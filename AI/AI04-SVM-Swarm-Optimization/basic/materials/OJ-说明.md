# SVM（Basic 小型分类实验）

## 题目描述

对已分开的训练集、开发集和测试集分别训练线性 SVM 与 RBF-SVM。必须把 `StandardScaler` 与 `SVC` 放入同一 Pipeline，仅在训练集上 `fit`；只能用开发集选少量 $C/\gamma$ 配置，冻结后对测试集预测。

## 输入格式

第一行为 `n_train n_dev n_test d`。

- 之后 `n_train` 行：$d$ 个特征和标签（-1 或 1）；
- 之后 `n_dev` 行：$d$ 个特征和标签；
- 最后 `n_test` 行：仅有 $d$ 个特征。

## 输出格式

先输出线性 SVM 对全部测试样本的 `n_test` 个预测，再输出 RBF-SVM 的 `n_test` 个预测。只允许 -1 或 1，空白分隔。

checker 对两个模型分别计算测试准确率，每个模型占该测试点的 50%。门槛只用于防止无效实现，不是课程成绩的“必须达到某个准确率”结论。

## 完整 Basic 提交

OJ 不能从预测结果单独证明无数据泄漏。仓库还须提交源码、划分记录、真实指标、混淆矩阵、边界图或预测表和 Q1-Q5。

## 数据范围

$2\le d\le20$，每个集合同时含有两类。时间限制 20 s，内存限制 1 GiB。
