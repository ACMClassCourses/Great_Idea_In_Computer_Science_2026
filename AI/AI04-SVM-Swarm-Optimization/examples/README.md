# 示例程序

请从项目根目录按编号运行：

- `00_self_check.py`：分模块检查十二项 TODO 的接口与基本性质；
- `01_iris_naive_svm.py`：在 Iris 二分类任务上比较 NaiveSVM 与 sklearn SVC；
- `02_test_functions.py`：在 Sphere 函数上验证 GA 与 PSO；
- `03_quick_demo.py`：运行小预算 MADELON 端到端实验；
- `04_full_experiment.py`：运行正式多种子实验及消融实验。

公开自检不包含参考实现，只检查形状、边界、预算、可行性、复现性和基础数值关系。
