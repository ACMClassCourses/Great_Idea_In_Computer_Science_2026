# AI6：Transformer

## A 问题是什么

处理一句话时，一个位置怎样利用其他位置的信息？Transformer 用注意力组织序列之间的信息交换。Basic 实现一次缩放点积注意力，核对权重与因果掩码；Advance 把多头注意力、位置表示、前馈网络等组件放到同一流程中，用结构实验解释信息如何流动。训练小型语言模型作为可选拓展。

| 阶段 | 工作量安排 | 难度 | 完成后的能力 |
| --- | --- | --- | --- |
| Basic | 一周内约 10-20 小时 | easy | 算清 Q/K/V、softmax 与掩码，展示注意力矩阵 |
| Advance | 完成 Basic 后再用六周 | medium | 实现多头和最小 Transformer 块，解释结构与训练目标 |

主线只需小矩阵和 CPU，不要求训练大语言模型。随机权重的热力图不能当作模型“理解了语义”的证据。

### Basic：把一次注意力计算看清楚

#### 1 学习目标与需要回答的问题

完成 Basic 时提交 **Q1-Q5**，Q5 附矩阵计算。

| 编号 | 需要回答的问题 | 回答应包含的内容 |
| --- | --- | --- |
| Q1 | token 和向量是什么关系？ | token 是序列单元，经表示变成向量；不必恰好等于一个汉字或单词 |
| Q2 | Q、K、V 各参与哪一步？ | Q/K 算匹配，归一化权重对 V 加权求和 |
| Q3 | softmax 应沿哪一维计算？ | 对每个查询的候选键归一化，即本项目矩阵的每一行 |
| Q4 | 因果掩码屏蔽什么？ | 第 i 行不能访问 j>i 的未来位置；在 softmax 前屏蔽 |
| Q5 | Q=K=V 为 2×2 单位阵，d_k=2，A 和 O 是多少？ | 分别计算无掩码和因果掩码，解释第一行的变化 |

#### 2 本周用到的注意力（先读这段）

**向量不是词本身。** 先用手写或固定随机向量代表三个位置，暂不训练词嵌入。输入 X 乘三组矩阵得到 Q/K/V。

```text
Q = X W_Q，K = X W_K，V = X W_V
S = Q K^T / sqrt(d_k)
A = softmax(S + mask)，按行计算
O = A V
```

**每行是一份“读信息”的权重。** A 的第 i 行表示第 i 个位置如何混合 V 的各行。权重非负、行和为 1；缩放因子使高维点积的量级更容易控制。

**掩码规定哪些位置可见。** 允许的位置加 0，禁止的位置加负无穷，softmax 后禁止位置变为 0。本项目保留对角线，保证每行至少一个可见位置。

| 对象 | 形状（单样本） | 含义 |
| --- | --- | --- |
| X | n×d_model | n 个位置的输入 |
| Q、K | n×d_k | 查询与键，维数必须相同 |
| V | n×d_v | 被汇总的信息 |
| A | n×n | 位置对位置的权重 |
| O | n×d_v | 加权后的输出 |

| 编号 | 材料 | 建议用法 |
| --- | --- | --- |
| B1 | [NumPy 入门](https://numpy.org/doc/stable/user/absolute_beginners.html) | 数组形状、转置、矩阵乘法 |
| B2 | [The Annotated Transformer](https://nlp.seas.harvard.edu/2018/04/03/attention.html) | 先读 Scaled Dot-Product Attention |
| B3 | [注意力代码](attention.py) | 对照投影、逐行 softmax 与掩码 |

#### 3 代码任务：单头注意力前向计算

可以调用矩阵乘法；投影、缩放、掩码、逐行归一化和加权求和需自行组织，不能只调用完整注意力接口。

1. 接收 X 与三组投影矩阵，检查形状和非空序列。
2. 实现数值稳定 softmax：先减每行最大值，再求指数与归一化。
3. 支持因果掩码开关，屏蔽严格上三角，保留对角线。
4. 打印 Q/K/V、S、A、O 的形状和数值，画小矩阵热力图。
5. 检查行和、非负性、被屏蔽位置与输出形状。

```bash
python -m pip install -r requirements.txt
python attention.py
```

`attention.py` 是完整教学参考，已含手算、单位置、修改未来与打乱顺序实验。先复现数字，再用自己的小矩阵说明过程；Basic 不要求优化器或训练语料。

#### 4 用一个小例子核对

```text
无掩码：A ≈ [[0.669762, 0.330238],
              [0.330238, 0.669762]]
因果掩码：A ≈ [[1.000000, 0.000000],
                [0.330238, 0.669762]]
```

因为 V 是单位阵，O=A。无掩码时第一行还会读取第二个位置；开启因果掩码后只能读取自己。不能先 softmax 再简单把未来权重置零，那样通常破坏行和为 1 的性质。

#### 5 Basic 提交与验收

提交源码、矩阵日志、权重图、Q1-Q5。验收要求与手算相符；单个位置时 O=V；开启掩码后只修改未来输入，较早位置的输出不变。数值容差可以设为 `1e-6`。

### Advance：从一次注意力到一个 Transformer 块

#### 1 学习目标与难度

Advance 要回答：**注意力之外，位置、多头和逐位置变换各自解决了什么问题？** 主线是可检查的结构实现，不以生成文章是否流畅验收。

| Goal | 学习目标与完成要求 | 难度 |
| --- | --- | --- |
| G1 | 解释原始 Transformer 的编码器、解码器与交叉注意力 | easy |
| G2 | 固定小矩阵、种子和结构实验协议 | easy |
| G3 | 实现多头注意力与一个最小 Transformer 块 | medium |
| G4 | 加入位置表示，记录每层形状和掩码行为 | medium |
| G5 | 用干预实验比较有/无位置、有/无因果掩码 | medium |
| G6 | 从第 5 节选择一个方向阅读 | 按方向 |
| G7 | 结构图、阅读笔记和 presentation | medium |

G1-G7 均需完成，G6 只选一个。完整语言模型训练不是主线必做项。

#### 2 会用到的组件（同样先读这段）

**多头是多组投影。** 可令 `d_model=32`、头数 4、每头维数 8。每头独立计算注意力，拼接后乘输出投影；不是把同一张权重图复制四次。

**位置表示提供顺序信息。** 不加位置、没有掩码时，自注意力对行置换具有相应的置换等变性。内容顺序改变后输出随之重排，不能单靠内容区分“谁在前”。

**前馈网络在每个位置内部变换。** 注意力跨位置交换信息，FFN 对每个位置使用同一组参数。残差保留输入通路，LayerNorm 归一化隐藏维。

```text
X = token 向量 + 位置向量
Y = X + MultiHeadAttention(LayerNorm(X), mask)
Z = Y + FFN(LayerNorm(Y))
```

这是便于实现的 pre-norm 教学块；原论文图中的 post-norm 顺序不同，报告应明确采用哪一种。可使用 PyTorch 的 Linear、LayerNorm、激活函数，注意力核心仍由自己组织。

| 编号 | 材料 | 建议用法 |
| --- | --- | --- |
| A1 | [Attention Is All You Need](https://arxiv.org/abs/1706.03762) | 主文献；结构图、注意力、位置编码 |
| A2 | [The Annotated Transformer](https://nlp.seas.harvard.edu/2018/04/03/attention.html) | 对照张量重排、多头与前馈网络 |
| A3 | [阅读路线](advance/README.md) | Encoder-only、Decoder-only、Encoder-Decoder |

#### 3 方法实现与过程展示（G2-G4）

1. 单头核对通过后增加 batch 与 head 维，注意 Q/K/V 的维度重排。
2. 掩码可广播到各 batch/head；有 padding 时明确屏蔽键位置，并避免一整行全被屏蔽。
3. 拼接多头后输出回到 d_model，检查残差相加形状。
4. 加正弦或可学习位置表示，固定输入与随机参数。
5. 用 `eval()` 或关闭 Dropout 做干预核对，避免随机噪声被误判为结构影响。

至少使用长度 1、2、8 的序列。对小尺寸随机矩阵与成熟注意力实现对照时，核对双方掩码 True/False 的含义、缩放和 Dropout 设置，不只对齐函数名字。

#### 4 比较方法并解释结果（G5 · medium）

以下实验无需训练，报告数值误差与现象，而非伪造语言任务准确率。

| 条件 | 干预 | 应检查的性质 |
| --- | --- | --- |
| 无位置、无掩码 | 同步重排输入行 | 输出按相同排列变化，误差接近 0 |
| 加位置、无掩码 | 重排内容，位置仍按原索引分配 | 一般不再等于简单重排输出 |
| 开启因果掩码 | 只改后续位置 | 前面位置输出保持不变 |
| 关闭因果掩码 | 只改后续位置 | 前面输出可能改变 |

位置实验不能把“内容+位置”整体一起重排后声称已证明位置无效。提交最大绝对误差、权重热力图和形状表，并解释：训练可并行计算已知序列各位置，生成下一 token 通常仍需逐步进行。

## C 问题的来龙去脉与发展过程

**从递推到直接交换信息。** 序列模型需要利用上下文，注意力允许按当前位置的需要组合其他位置的信息。Transformer 把自注意力放到结构中心，并结合位置编码与逐位置前馈网络。[原论文](https://arxiv.org/abs/1706.03762)

**从一个权重矩阵到完整架构。** 多头、残差和归一化各有不同职责。2017 年的 Transformer 是编码器-解码器模型，今天常见的自回归模型只是相关架构的一类，不能把一次注意力运算等同于完整模型。[Annotated Transformer](https://nlp.seas.harvard.edu/2018/04/03/attention.html)

**从能运行到能解释。** 小矩阵实验能检查因果性、顺序信息和形状；语言能力还需要训练数据、目标与优化。把这两层证据分开，是本项目的主要学习目标。
