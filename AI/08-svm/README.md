## A 问题是什么

给一批带标签的数据，支持向量机（SVM）怎样找到分类边界？模型的超参数又应该怎样选择？本项目分两段：Basic 在小型二分类数据上训练线性和 RBF-SVM，理解间隔、核函数和验证集；Advance 自行实现粒子群优化（PSO），在相同评价预算下与随机搜索比较，检验“更复杂的搜索是否值得”。

| 阶段 | 工作量安排 | 难度 | 完成后的能力 |
| --- | --- | --- | --- |
| Basic | 一周内约 10-20 小时 | easy | 用小数据训练 SVM，解释 C、gamma 与分类边界 |
| Advance | 完成 Basic 后再用六周 | medium | 实现 PSO、建立无泄漏评价、比较准确率与搜索成本 |

不要求 GPU。Basic 可使用成熟 SVM 库，不要求一周内手写 SMO。参考 [v0：08-svm](../v0/Great_Idea_In_Computer_Science_TA_2026-main/08-svm/README.md)；原版包含 SMO、GA、混合 PSO 和特征选择。本说明缩小主线：**PSO 调 C/gamma 必做，联合特征选择和 GA 选做**，原版全部 TODO 不作为七周任务的前置条件。

#### 2 本周用到的 SVM 概念（先读这段）

**边界是一条分数为零的线。** 线性 SVM 先计算 `f(x)=w·x+b`。正负号决定类别，`|f(x)|/||w||` 才是到超平面的几何距离。分数不是自动校准好的概率。

**分对还不够，希望留出间隔。** `y*f(x)>=1` 表示满足单位函数间隔；位于正确一侧但太靠近边界，也会有 hinge loss。软间隔允许违反约束，用 C 调节惩罚强度。

**核函数让边界弯曲。** RBF 核计算 `exp(-gamma*距离平方)`，距离近的样本相似度高。gamma 大时相似度随距离衰减更快；不等于“参数越大越好”。

| 名字 | 人话 | Basic 要不要 |
| --- | --- | --- |
| StandardScaler | 用训练数据的均值和标准差统一尺度 | 要 |
| 线性 SVM | 学一条直线或超平面 | 要，作为对照 |
| RBF-SVM | 用相似度表达非线性边界 | 要 |
| SMO | 求解 SVM 对偶问题的一种算法 | 暂不要求手写 |
| PSO | 在候选超参数之间搜索 | Advance 再做 |

| 编号 | 材料 | 建议用法 |

#### 3 代码任务：可解释的小型分类实验

使用 Iris 的两个类别，或固定种子生成 200-500 个二维二分类点。自己编写一个独立 Basic 脚本，避免被原版 SMO 的 TODO 阻塞。

1. 固定分层训练/开发/测试划分，如 60%/20%/20%，记录样本数。
2. 将 `StandardScaler` 和 `SVC` 放入同一个 Pipeline；只在训练集 `fit`。
3. 比较线性核与 RBF 核。只用开发集选择少量 C/gamma 配置。
4. 冻结配置后在测试集评价一次，报告 accuracy、混淆矩阵与样本数。
5. 二维数据画边界和支持向量；高维数据不能把任意二维投影当成完整边界。

```python
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

model = make_pipeline(
    StandardScaler(),
    SVC(kernel="rbf", C=1.0, gamma="scale"),
)
# 在自己的脚本中准备 X_train、y_train，再调用 fit 和 predict。
```

依赖可用 `python -m pip install numpy scikit-learn matplotlib` 安装。上述片段是建模示意，数据划分、记录和绘图由学生补充，不是已完成的实验。

#### 4 用一个小例子核对

| 点 | f(x) | y*f(x) | 预测 | hinge loss |
| --- | ---: | ---: | --- | ---: |
| 1 | -3 | 3 | -1，正确 | 0 |
| 2 | -1 | 1 | -1，正确 | 0 |

#### 2 会用到的方法（同样先读这段）

**一个粒子就是一组参数。** 令位置为 `(u,v)`，再转成 `C=10^u`、`gamma=10^v`。这样移动一个单位表示参数改变十倍，适合搜索跨数量级的参数。

**粒子会记住自己和群体的好位置。** pbest 是该粒子历史最好位置，gbest 是群体历史最好位置；两个随机数让探索保留随机性。

```text
velocity = w*velocity + c1*r1*(pbest-position)
                       + c2*r2*(gbest-position)
position = position + velocity
loss = 1 - 训练部分内部的平均 CV accuracy
```

设置速度限制、位置边界和固定种子；历史最优值要复制保存，不能引用后来还会变化的数组。只在真实评价后更新 pbest/gbest。

| A2 | [scikit-learn：SVM](https://scikit-learn.org/stable/modules/svm.html) | 核参数与训练接口 |

#### 3 方法实现与过程展示（G2-G4）

先在 `Sphere(x)=sum(x*x)` 上检查：固定种子可重复、位置不越界、历史最优损失不增、实际候选评价次数不超过预算。再接入 SVM。

可使用 MADELON 官方 Training 做搜索，官方带标签 Validation 作为**本项目封存的最终测试集**；名称是 Validation，不代表能反复看它调参。不使用无公开标签 Test。机器较慢可在 Training 内固定抽样，并把规模写清。

**统一协议：**

1. 训练部分内部固定分层 3 折 CV；每折分别拟合标准化，不能先对全训练部分标准化再 CV。
2. 搜索范围如 `u∈[-3,3]`、`v∈[-4,1]`；RandomSearch 与 PSO 使用相同范围与折划分。
3. 每种搜索每个种子评价 B=30-60 个候选即可；初始化粒子也计入 B。
4. 缓存策略保持一致，同时报告提议数、唯一候选数与 SVC 拟合次数。
5. PSO 参数和预算在测试前确定，最终测试只用于报告已冻结方法。

采用本说明的独立连续 PSO 入口即可。`v0/examples/03_quick_demo.py` 调用的是更大的混合任务，须完成其相关 TODO 才能运行；不能把它当作本次的现成完整答案。

## C 问题的来龙去脉与发展过程

**从分开样本到保留间隔。** SVM 用间隔与误差惩罚刻画分类边界，核函数让这种思路扩展到非线性关系；参数选择仍需要与训练分开的评价流程。[SVM 文档](https://scikit-learn.org/stable/modules/svm.html)

**从求解模型到搜索黑盒配置。** 外层每次只拿到一次训练/CV 的结果，可以将其视为昂贵的黑盒评价。1995 年提出的 PSO 用个体和群体历史信息引导搜索；它提供搜索策略，不承诺每次都找到最优参数。[PSO 原论文](https://doi.org/10.1109/ICNN.1995.488968)

**从最好分数到有限预算比较。** 高维噪声数据让特征与参数选择更困难。公平比较需要同时记录评价次数、拟合次数和波动，本项目先用两个参数掌握这一实验思想，再阅读混合优化。[MADELON](https://archive.ics.uci.edu/dataset/171/madelon)
