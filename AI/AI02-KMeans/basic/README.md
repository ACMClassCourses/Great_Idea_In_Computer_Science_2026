# K-means：Basic — 用均值寻找数据中的分组

## 项目介绍

没有预先给定类别的样本，能不能仅凭坐标发现分组？K-means 用 `K` 个中心概括数据：每个样本属于离自己最近的中心，每个中心又是簇内样本的均值。“簇”就是算法得到的一组样本，它的编号只是名字，不一定对应现实中的类别。

你将先手算、再用 Python 实现、最后绘图，完成一个小而完整的聚类实验。建议安排 **1 周，约 10–20 小时**。需会使用循环、列表和函数；绘图部分可边做边学。不要求 K-means++、肘部法、自动选择 K 或 MNIST。

## 简要算法介绍

本项目采用批量的 Lloyd 迭代：

1. 选择输入给定的 `K` 个初始中心。
2. 固定中心，把每个样本分给最近中心。
3. 固定分组，将每个非空簇的中心更新为坐标均值。
4. 重复，直到标签不再变化；设置最大迭代次数作为保护。

二维距离平方为 `(x-a)² + (y-b)²`。比较距离平方不必开方，因为开方不会改变大小关系。距离相同统一选择编号较小的簇。非空簇的新中心为 `(横坐标均值, 纵坐标均值)`。

结果用簇内平方误差和 **SSE** 描述：

```text
SSE = 所有点到自己所属中心的距离平方之和
```

SSE 是距离指标，不是分类准确率。聚类收敛也不保证全局最优；初始中心、K 和数据特征都可能影响结果。

## 任务 Q1：手算两轮

令 `K=2`，初始中心为 `C0=(1,1)`、`C1=(8,8)`：

```text
(1,1), (1,2), (2,1), (2,2), (8,8), (8,9), (9,8), (9,9)
```

至少记录两轮。每轮列出每个点到两个中心的距离平方、簇编号、各簇包含的点、更新后的中心和停止判断。回答：

- 固定中心时，为什么选最近中心？
- 固定分组时，为什么取均值？
- 第二轮与第一轮相比，分组是否变化？

## 任务 Q2：独立实现核心循环

用 Python 自行实现距离、分配、更新和迭代函数，可用标准库；也可以用 NumPy 保存数组。**不得用现成 K-means 函数替代核心循环。** 请通过 Q1 的手算结果和自行设计的测试检查实现。

程序读取样本数、K、二维点和指定初始中心，输出最终 SSE、中心与标签。建议主循环：

```text
labels = 尚未分组
最多循环 max_iterations 次：
    new_labels = 按当前中心分配样本
    若 new_labels 与 labels 相同：停止
    labels = new_labels
    centers = 按 labels 计算均值
```

达到上限时应明确报告未收敛，不能把它当作标签稳定。输出的中心必须对应最终分组。Basic 的规定样例不要求复杂空簇策略，但应说明空簇不能求均值；若自行测试时出现空簇，可保留旧中心并记录该策略。

## 任务 Q3：绘制结果

使用 Matplotlib 将各簇画成不同颜色，中心使用较大且不同形状的标记；补齐标题、坐标轴和图例，保存 PNG。图中应同时看到样本与中心，不要只截图命令行。

## 输入输出约定

输入：

```text
n k
x1 y1
...
xn yn
center0_x center0_y
...
center(k-1)_x center(k-1)_y
```

`n>0`，`1≤k≤n`；中心按输入顺序编号为 `0–k-1`。使用浮点数计算，最后输出时才保留 3 位小数，不要每轮都把中心截断到 3 位。

输出共 `k+2` 行：第一行 SSE，接下来 k 行中心坐标，最后一行是按输入顺序排列的 n 个簇编号。Q1 样例的输出为：

```text
4.000
1.500 1.500
8.500 8.500
0 0 0 0 1 1 1 1
```

标准输出只放规定答案；逐轮调试信息放入报告或单独的演示模式。

## 算法发展历程

| 时间 | 发展 | 与本项目的关系 |
| --- | --- | --- |
| 1957 年的工作，1982 年发表 | Lloyd 研究最小平方误差量化 | 交替“分配—更新”成为常用批量迭代 |
| 1967 年 | MacQueen 使用 K-means 名称，讨论多维观测分类 | 聚类从二维示意走向多维数据分析 |
| 2007 年 | Arthur 与 Vassilvitskii 提出 K-means++ | 改善初始中心选择，后续仍用普通迭代 |

K-means 没有预先给定标签，属于无监督学习。它偏好围绕均值、尺度接近的簇；非球状数据、离群点和尺度差异可能让结果违背直觉。这些局限将成为 [Advance](../advance/README.md) 的实验内容。

参考：[Lloyd 论文](https://doi.org/10.1109/TIT.1982.1056489)、[MacQueen 论文](https://digicoll.lib.berkeley.edu/record/113015?v=pdf)、[scikit-learn 聚类说明](https://scikit-learn.org/stable/modules/clustering.html#k-means)。
