# K-means：Basic（基础阶段）— 用均值寻找数据中的分组

## 项目介绍

一批点没有预先标明类别，能不能仅凭坐标发现分组？这种根据数据的相似程度自动分组的做法叫“聚类”。K-means（K 均值）用 `K` 个中心概括数据，`K` 是你事先指定的组数。本阶段把每个点叫作一个“样本”，把算法分出的一组样本叫作一个“簇”。每个样本分给离自己最近的中心，再用每组样本的平均坐标作为新中心。“均值”就是平均值，例如 `(1,1)` 和 `(3,5)` 的平均坐标是 `(2,3)`。簇的编号只是名字，不一定对应现实中的类别。

你将先手算、再用 Python 实现、最后绘图，完成一个小而完整的聚类实验。建议安排 **1 周，约 10–20 小时**。需会使用循环、列表和函数；绘图部分可边做边学。更好的初始中心选择方法、自动选择组数和手写数字数据实验留到 Advance，本阶段无需掌握。

## 简要算法介绍

先准备初始中心，再反复执行“分组—更新”。每执行一次“分组—更新”称为“一轮迭代”。每轮先给所有点分组，再一起更新中心，这种做法也叫 Lloyd（劳埃德）迭代：

1. 读入给定的 `K` 个初始中心；这一步只做一次。
2. 保持中心不动，把每个样本分给最近中心。
3. 保持这次分组不变，将每个有样本的簇的中心更新为坐标均值。
4. 重复第 2、3 步，直到相邻两轮中每个点所属的簇都相同；另设最大迭代次数，防止程序一直运行。点所属的簇编号也叫它的“标签”，这里是算法算出的编号，不是事先给出的正确答案。

点 `(x,y)` 到中心 `(a,b)` 的距离平方为 `(x-a)² + (y-b)²`。比较距离平方不必开方，因为开方不会改变大小关系。到两个或多个中心的距离相同时，统一选择编号最小的簇。非空簇的新中心为 `(横坐标均值, 纵坐标均值)`。

为了用一个数描述各组的紧密程度，我们计算所有点到各自中心的距离平方之和，称为“簇内平方误差和”，缩写为 **SSE**：

```text
SSE = 所有点到自己所属中心的距离平方之和
```

例如，点 `(1,1)` 到中心 `(1.5,1.5)` 的距离平方为 `0.5`，它对 SSE 的贡献就是 `0.5`。SSE 越小，表示点在距离意义上越靠近各自中心，但不代表分组就越符合现实中的类别。当分组不再变化时，我们说算法“收敛”了；这只说明当前步骤无法继续改变分组，不能保证它是所有可能分组中 SSE 最小的那个。初始中心、K 和用于描述数据的数值都可能影响结果。

## 任务 Q2：独立实现核心循环

用 Python 自行实现距离、分配、更新和迭代函数，可用标准库；也可以用 NumPy 保存数组。**不得用现成 K-means 函数替代核心循环。** 请通过 Q1 的手算结果和自行设计的测试检查实现。

程序读取样本数、K、二维点和指定初始中心，输出最终 SSE、中心与簇编号。下面是主循环的伪代码（用于说明步骤，不是可直接运行的 Python 代码）；`labels` 保存上一轮分组，`new_labels` 保存本轮分组，`centers` 保存中心：

```text
labels = 尚未分组
最多循环 max_iterations 次：
    new_labels = 按当前中心分配样本
    若 new_labels 与 labels 相同：停止
    labels = new_labels
    centers = 按 labels 计算各组均值；没有样本的组保留旧中心
```

其中 `max_iterations` 是最多允许执行的轮数，可先设为 100，并在报告中记录。第一次分组时还没有上一轮结果，因此不能判断分组是否稳定。第二轮起，若所有簇编号与上一轮相同，就可以停止，此时中心已经是上一轮算出的均值，不必再更新一次。

达到上限仍未确认分组稳定时，应明确报告“尚未确认分组稳定”，不能把它当作正常收敛。错误或未收敛提示可写到标准错误输出（先 `import sys`，再用 `print(..., file=sys.stderr)`），不要混入下文约定的答案格式。

输出的中心必须对应最终分组。“空簇”是没有任何点被分入的簇，无法计算均值；如果出现空簇，本阶段保留它的旧中心，并在报告中说明。这样仍可能有中心没有分到点，不保证一定得到 K 个非空组。

## 输入输出约定

输入：

```text
n k
x1 y1
...
xn yn
center0_x center0_y
...
center(k-1)_x center(k-1)_y
```

这里 n 表示样本数，k 表示簇数（即前文的 K）；接下来是 n 行样本坐标和 k 行初始中心坐标。要求 `n>0`、`1≤k≤n`；中心按输入顺序编号为 `0–k-1`。使用能保存小数的数值类型计算，最后输出时才四舍五入保留 3 位小数，不要每轮都舍入中心坐标。

输入格式中的 `...` 表示省略的行，实际输入时不写省略号。以 Q1 为例，完整输入为：

```text
8 2
1 1
1 2
2 1
2 2
8 8
8 9
9 8
9 9
1 1
8 8
```

正常完成时，输出共 `k+2` 行：第一行 SSE，接下来 k 行按中心编号顺序输出坐标，最后一行是按样本输入顺序排列的 n 个簇编号。同一行的多个数之间用空格分隔。Q1 样例的输出为：

```text
4.000
1.500 1.500
8.500 8.500
0 0 0 0 1 1 1 1
```

## 算法发展历程

| 时间 | 发展 | 与本项目的关系 |
| --- | --- | --- |
| 1957 年的工作，1982 年发表 | Lloyd 研究如何用少量代表值近似原始数值，并减小平方误差 | 形成了每轮先给所有点分组、再更新全部中心的做法 |
| 1967 年 | MacQueen 使用 K-means 名称，讨论由多个数值描述的样本如何分组 | 同样的分组思路也可用于不止两个坐标的数据 |
| 2007 年 | Arthur 与 Vassilvitskii 提出 K-means++ | 改善初始中心选择，后续仍用普通迭代 |

K-means 不需要预先给出的正确类别，这类学习方法称为“无监督学习”。它比较适合一团团近似圆形、大小相近的点。环形的点、远离大多数样本的点（离群点），或数值范围差异很大的坐标，都可能使结果不符合直觉。这些局限将成为 [Advance](../advance/README.md) 的实验内容。

参考：[Lloyd 论文](https://doi.org/10.1109/TIT.1982.1056489)、[MacQueen 论文](https://digicoll.lib.berkeley.edu/record/113015?v=pdf)、[scikit-learn 聚类说明](https://scikit-learn.org/stable/modules/clustering.html#k-means)。
