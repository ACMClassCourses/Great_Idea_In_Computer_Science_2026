# K-means：Advance（进阶阶段）— 从算法循环到数据实验

## 项目介绍

Advance 将 [Basic](../basic/README.md) 的二维分组程序扩展到多维数据，要求能检查结果、记录实验步骤，让别人也能得到相同结果。你将研究初始中心、数据形状和各特征的数值范围如何影响分组。“特征”就是描述一个样本的一项数值，例如描述一个人的身高或体重。

在完成 Basic 后追加 **5 周**，与 Basic 合计 6 周。需要熟悉 Python 函数与列表、坐标运算和绘图。“多维数据”是用多个数描述一个样本，例如用身高、体重、年龄三个特征描述一个人。把这些数按固定顺序列在一起就是“向量”；特征数就是“维数”。中心也用同样数量、同样顺序的数值表示。你应最终能解释结果为什么出现，以及算法在哪些数据上不适合使用。

## 简要算法介绍

主体仍是 Basic 的 Lloyd 迭代：保持中心不动，将样本分给最近中心；再保持分组不变，计算各组均值。算法希望减小的误差仍然是 SSE，即所有样本到各自中心的距离平方之和：

```text
SSE = 所有样本到各自所属中心的距离平方之和
一个样本的距离平方 = 各个特征的“样本值 − 中心值”的平方相加
```

例如三维样本 `(1,2,3)` 到中心 `(2,2,1)` 的距离平方为 `1+0+4=5`。固定中心时，分给最近中心能让每个点对 SSE 的贡献最小；固定分组时，均值能让簇内平方距离和最小。因此按这两步更新，SSE 不应增加，小数计算可能带来极小误差。但从某个起点得到稳定分组，并不保证找到了所有可能分组中 SSE 最小的结果；换一组初始中心可能得到更好的结果。

**K-means++** 改进初始中心的选择：第一个中心从样本中随机选出，每个样本被选中的概率相同；之后计算每个点到最近已选中心的距离平方，再按这些值分配被选中的概率。这叫“按距离平方加权抽样”：某个点被选中的概率等于它的距离平方除以所有点的距离平方总和。例如只有两个候选点，距离平方分别为 1 和 9，它们被选中的概率就是 10% 和 90%。这样较远的点更容易被选中，但并非每次都选最远点。重复到选满 K 个中心；它不负责决定 K。

如果距离平方总和为 0，说明剩余点的坐标都已被现有中心覆盖，不能再按该公式计算概率。选做实现时需说明如何处理，例如从尚未选过的样本中随机补足，并允许不同样本的坐标相同。

如果每个 K 都能找到最好的分组，增加中心个数不会使 SSE 变大。但实际运行从不同初值出发，未必都能找到最好结果，画出的曲线也可能出现波动。不能只因 SSE 小就选最大的 K：当 K 等于样本数、每个点各成一簇时，SSE 可以为 0，却没有概括数据。肘部法是寻找“SSE 原本下降很快、随后明显变缓”的转折；轮廓系数则比较一个点与本簇、其他簇的接近程度。两者都只能辅助判断，不要求每组数据都找到唯一答案。

## 必做任务

1. **多维实现**：支持用户指定中心，也支持随机选择样本作为初始中心；设置最大迭代次数和“中心移动小于多少就停止”的阈值，例如 `0.0001`。“阈值”就是用于判断是否停止的界限。写清如何计算移动距离，例如计算每个中心到上一轮位置的距离，所有中心的移动距离都小于阈值时停止。返回中心、簇编号、迭代次数、停止原因和 SSE，并记录每轮 SSE。
2. **边界处理**：检查空数据、非法 K（n 为样本数，本项目要求 `1≤K≤n`）、样本或初始中心的特征数不一致、NaN（表示“不是有效数值”的特殊值，如缺失数据可能用它表示）或无穷值，以及小于等于 0 的最大迭代次数、负的移动阈值；测试多个样本坐标相同的“重复点”和没有分到样本的“空簇”，写明处理方法。
3. **初值实验**：固定数据、K、数据处理方式与停止条件，比较至少 5 个随机种子。种子是随机数生成器的起始设置，同一种子便于重复相同实验。报告分组、SSE 和迭代次数，不要只选最好结果。
4. **初始化学习**：解释 K-means++ 的加权抽样流程。自行实现为选做；必做的是理解并分析初值影响。
5. **数据形状实验**：比较几种点的分布：彼此分开的几团、互相重叠的几团、各团点数差异很大的数据，以及至少一种不呈圆团状的数据，如环形或两条弯月形的点带（双月形）。这些数据可自行生成，提交图与解释。
6. **特征数值范围与真实数据实验**：自行选择一组可公开获得的数据，记录来源，说明每个特征的含义以及运行算法前如何处理数据，比较原值与标准化后的结果。标准化方法见下文。
7. **库实现对照**：使用 Python 库 scikit-learn 的 KMeans 作比较，明确传入相同初始中心，并设 `n_init=1`（只运行一次，不让库自动尝试多组初值）。尽量统一最大迭代次数，说明停止条件的差异；核心循环仍需自己实现。

空簇是没有分到样本的组，不能求均值。可以保留旧中心，或另选样本作为它的新中心。写清选择方法并检查 SSE，额外移动中心或改变分组后不要直接假定误差一定下降。到多个中心的距离相同时，沿用 Basic 的规则，选择编号最小的簇。遇到迭代上限，要标明未按收敛条件停止。

为使逐轮 SSE 可比较，每轮在完成分配和更新后记录一次，并确保计算 SSE 时使用的中心和簇编号来自同一轮。输出的非空簇中心应是所输出分组的均值。如果因为中心移动很小而停止，分组未必已经完全稳定，应如实记录停止原因。不要只重新分组却不更新中心，导致输出的中心和分组不对应。

## 实验安排

| 实验 | 比较方法与条件 | 观察与解释 |
| --- | --- | --- |
| 正确性 | 使用指定中心、可手算的小数据 | 中心是否为均值，SSE 是否与手算一致 |
| 边界 | 分别构造 K=1、重复点、空簇和非法数据 | 程序如何停止、报错或执行约定的处理方法 |
| 初值 | 数据、K、运行前的数据处理和停止条件不变，只更换随机种子 | 初始中心的变化如何影响最终 SSE 或迭代次数 |
| 几何形状 | 尽量保持样本数和 K 不变，改变点团的分离程度或形状 | 按最近中心分组为什么不适合某些形状 |
| 特征数值范围 | 对同一数据分别使用原值与标准化值 | 数值范围大的特征如何更强地影响距离 |
| 库对照 | 使用相同初始中心，库设为 `n_init=1` | 差异是否来自计算精度、停止条件或空簇处理方法 |

比较时，让不研究的条件尽量保持不变，这叫“控制变量”。例如研究初始中心时，数据和 K 都不应同时改变。

**为什么要标准化？** 若一个特征是几万的收入，另一个是几十的年龄，前者容易主导距离。可对每个特征分别计算 `(原值−该特征均值)/该特征标准差`；标准差衡量数值分散的程度，可用 NumPy 等工具计算，不要求手写统计函数。若某个特征所有值都一样，就将这一列设为 0 或删除，避免除以 0。

建议每次运行记录数据来源或生成种子、样本数、维数、K、初始中心选择方法、数据处理、停止条件、SSE、迭代次数和运行时间。标准化改变了距离的单位，因此不能直接比较前后的 SSE 数字来判断优劣，还应看分组图和特征含义。多维数据可以选择两个特征画图，但需注明图中只展示了部分特征，算法使用了哪些特征也要写清。

本阶段的真实数据实验不强制划分训练集和测试集。如果选择下面的手写数字等预测实验，再按相应说明划分。训练集用于建立分组，测试集用于检查对新样本的效果；标准化的均值和标准差只能从训练集计算，再用于转换两部分数据，以免提前用到测试数据的信息。

## 选做方向

完成必做任务后可选：

- 自行实现 K-means++，与随机初始化比较。
- 研究肘部法/轮廓系数，解释没有清晰答案的情况。
- MNIST 手写数字数据集：每张图是 28×28 个像素，用亮度表示数字形状。把像素按固定顺序排成 784 个数，再聚类。聚类时不用图片预先标注的正确数字；完成后，用训练样本中每簇最常见的数字为该簇命名。测试样本分给最近中心，检查预测数字是否正确，不能用测试答案来修改簇名。可把中心的 784 个数重新排成图像，并制作“真实数字与预测数字”的计数表（混淆矩阵）。一个数字可对应多个簇，簇编号也不是数字本身。
- 性能：用 NumPy 减少循环，比较耗时和中间数组内存。

如果要反复尝试 K 等参数，可另留一部分数据作验证集：用训练集运行算法，用验证集选择参数，最后才用测试集报告效果。报告中写清如何划分数据。数据较大时，可用固定随机种子抽取一小部分开始实验。

## 算法发展历程

Lloyd 研究如何用少量代表值近似原始数值，并尽量减小平方误差，由此形成“分配—更新”的做法。MacQueen 在 1967 年使用 K-means 名称讨论多维数据分类；不同文献的更新方式并不完全相同，本项目每轮先分配所有样本，再一起更新中心。

2007 年的 K-means++ 改善初始中心选择，但仍可能得到不同结果，也仍更适合一团团近似球形的数据（二维时可理解为近似圆形）。面对更大的数据，Mini-batch K-means（小批量 K-means）每次只用一小批样本更新中心，以节省时间；面对环形等复杂形状，其他聚类方法会根据样本是否密集相连或彼此如何连接来分组。这些发展说明，选择算法时需要考虑数据形状和任务目标。
