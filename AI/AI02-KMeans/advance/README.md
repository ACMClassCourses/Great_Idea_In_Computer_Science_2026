# K-means：Advance — 从算法循环到数据实验

## 项目介绍

能画出两团点，不等于能解释真实数据。Advance 将 [Basic](../basic/README.md) 的二维循环扩展为多维、可验证、可复现的实现，研究初始中心、数据形状和特征尺度如何影响结果。

在完成 Basic 后追加 **5 周**，与 Basic 合计 6 周。需要熟悉 Python 函数与列表、基本向量运算和绘图。你应最终能解释结果为什么出现，以及算法在哪些数据上不适合使用。

## 简要算法介绍

主体仍是 Lloyd 迭代：固定中心选择最近簇，固定分组计算均值。多维目标函数为：

```text
SSE = Σ ||x_i - μ(label_i)||²
```

固定中心时最近分配最小化每个点的贡献；固定分组时均值最小化簇内平方距离和。因此在约定一致的分配和更新下，SSE 不应增加，浮点计算可带来极小误差。目标不是凸函数，收敛到一个稳定结果并不证明全局最优。

**K-means++** 改进初始化：第一个中心均匀随机选择；之后按点到最近已选中心的距离平方加权抽样，直到选满 K 个。它不是每次选最远点，也不自动选择 K。

理论上的最优 SSE 随 K 增大而不增加，但独立初始化的实际运行可能落在不同局部结果，曲线不一定严格单调。不要只因 SSE 最小就选最大 K；肘部法、轮廓系数和领域知识都只是参考。

## 必做任务

1. **多维实现**：支持指定与随机初始中心、最大迭代次数、收敛阈值；返回中心、标签、迭代次数、停止原因和 SSE，并记录每轮 SSE。
2. **边界处理**：检查空数据、非法 K（本项目要求 `1≤K≤n`）、维数不一致、NaN/无穷值、非法停止参数；测试重复点和空簇，写明策略。
3. **初值实验**：固定数据、K、预处理与停止条件，比较至少 5 个随机种子，报告分组、SSE 和迭代次数，避免只选最好结果。
4. **初始化学习**：解释 K-means++ 的加权抽样流程。自行实现为选做；必做的是理解并分析初值影响。
5. **数据形状实验**：比较分离、重叠、数量不均和至少一种非球状数据（环形或双月形），提交图与解释。
6. **尺度与真实数据实验**：自行选择一组可公开获得的数据，记录来源，说明特征含义和预处理，比较原尺度与标准化的影响。
7. **库实现对照**：使用相同初始中心、`n_init=1` 和可比停止条件，与 scikit-learn 对照；核心循环仍需自己实现。

对于空簇，可以保留旧中心，或采用有解释的重新初始化策略。记录它如何影响 SSE；任意重分配后不能未经检查就宣称 SSE 必定下降。遇到迭代上限，要标明未按收敛条件停止。

## 实验矩阵

| 实验 | 控制变量 | 观察与解释 |
| --- | --- | --- |
| 正确性 | 指定中心、可手算小数据 | 中心是否为均值，SSE 是否与手算一致 |
| 边界 | K=1、重复点、空簇、非法数据 | 如何停止、报错或执行约定策略 |
| 初值 | 数据、K、预处理和停止条件不变 | 种子为何改变最终 SSE 或迭代次数 |
| 几何形状 | 改变分离程度或形状 | 最近均值为什么不适合某些结构 |
| 特征尺度 | 同一数据的原值与标准化值 | 大数值范围的特征如何主导距离 |
| 库对照 | 相同初值，库 `n_init=1` | 差异是否来自精度、停止或空簇规则 |

建议每次运行记录数据来源/生成种子、n、维数、K、初始化、预处理、停止条件、SSE、迭代次数和运行时间。只比较同一数据表示下的 SSE；标准化前后的数值单位不同，不能直接用绝对 SSE 判优。若有训练/测试划分，只用训练部分拟合标准化参数。

## 算法发展历程

Lloyd 的量化研究形成了批量“分配—更新”形式；MacQueen 在 1967 年使用 K-means 名称讨论多维观测分类，不同文献的更新方式并不完全相同。本项目采用整批分配、整批更新。

2007 年的 K-means++ 针对初值敏感性改进起点，并没有消除局部最优和几何假设。面对更大数据，Mini-batch K-means 用小批样本降低每次更新成本；面对复杂形状，密度或图结构聚类采用不同的建模方式。这些发展说明：没有一种距离和分组方式适合所有数据，算法选择要与数据及任务目标一致。
