# Project 3 Basic：DCP 图像去雾

请依照课程项目文档完成 `starter.py` 中的 TODO。框架同时支持：

- `python starter.py < case.in`：用于 OJ 小矩阵数值核对；
- 将核心函数复用到你的真实图像 CLI，保存输入、暗通道、粗透射率、恢复图与参数。

边界处理为复制填充。全流程使用 RGB、`float64` 和 $[0,1]$ 数值范围。完成后还要提交 Q1-Q5、真实图像来源、中间图和日志。

```bash
python -m pip install -r requirements.txt
python starter.py < 自备测试.in
```
