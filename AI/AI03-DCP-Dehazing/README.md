# AI3：DCP 图像去雾算法

## A 问题是什么

有雾照片常常灰白、低对比、远处细节模糊。怎样只用一张图估计雾的影响并恢复场景？DCP（Dark Channel Prior，暗通道先验）把“许多自然无雾区域里存在很暗的颜色通道”这一观察，与大气散射模型结合。Basic 跑通不细化透射率的最小流程；Advance 实现导向滤波，比较边缘、颜色、噪声与失败场景。

| 阶段 | 工作量安排 | 难度 | 完成后的能力 |
| --- | --- | --- | --- |
| Basic | 一周内约 10-20 小时 | easy | 理解暗通道、透射率，输出最小 DCP 去雾结果 |
| Advance | 完成 Basic 后再用六周 | medium | 实现保边细化，做消融实验，说明先验的边界 |

只需 Python、NumPy 和 OpenCV，无需训练网络或使用 GPU。对比度变高不等于真实颜色被恢复。

#### 2 本周用到的图像模型（先读这段）

**图像先变成浮点数。** 读图后转换浮点并除以 255；全流程固定通道顺序。不能直接在无符号整数上做恢复公式中的减法和除法。

**雾混合了两种光。** 散射模型把观测解释为衰减后的场景光，加上散射进来的大气光：

```text
I(x) = J(x) * t(x) + A * (1 - t(x))
I：有雾图；J：待恢复图；t：透射率；A：全局大气光
```

t 接近 1 时主要看到场景，接近 0 时主要看到大气光。Basic 会代入和移项即可，不要求推导散射物理。

**暗通道是两次取最小。** 每个像素取 R/G/B 最小值，再取局部窗口最小值。它用来估计雾，不是最后要交付的去雾图片。

#### 3 代码任务：最小 DCP

先用小尺寸合成图和两三张真实有雾图调试。需要自行组织四步，局部最小和均值可调用 NumPy/OpenCV。

1. 实现暗通道，使用奇数窗口，明确边界填充方式。
2. 取输入暗通道最亮的少量像素作候选，如前 0.1%、至少 1 个，再从对应原 RGB 像素中选亮度较高者估计 A；记录选择规则。
3. 先将各通道除以对应 A 分量，再计算暗通道以估计粗透射率。
4. 加透射率下限恢复 J，保存输入、暗通道、粗透射率、恢复图与参数。

```text
A_safe = max(A, epsilon)            # 各通道分别处理
t_raw = 1 - omega * dark(I / A_safe)
t_used = max(clip(t_raw, 0, 1), t0)
J = (I - A) / t_used + A
```

可从 `omega=0.95`、`t0=0.1`、窗口 15 开始。omega 控制去雾强度，t0 限制低透射率区域的放大。保存图时裁剪到 0-1，同时记录裁剪比例，不能靠裁剪掩盖异常值。

核心模块仍有 TODO。Basic 完成暗通道、大气光、粗透射率和场景恢复，使用 `--no-refine` 跳过尚未实现的导向滤波。自行准备 `hazy.png` 后运行：

```bash
python -m pip install -r requirements.txt
python dehaze.py -i hazy.png -o outputs/basic --no-refine
```

检查输出尺寸、A 的三个分量、t 的范围及 NaN/Inf。不要只保存最终图片。

#### 4 用一个小例子核对

Q5 已给定 t，验证的是恢复公式，**不是从单个像素估计 DCP 透射率**。

| 通道 | I | A | t | J=(I-A)/t+A |
| --- | ---: | ---: | ---: | ---: |
| R | 0.6 | 1 | 0.5 | 0.2 |
| G | 0.7 | 1 | 0.5 | 0.4 |
| B | 0.8 | 1 | 0.5 | 0.6 |

代回散射模型可得到 I。若 t=0.1，I 的 0.01 误差可能在 J 中变成 0.1。这解释浓雾区噪声放大，以及设置 t0 的原因。

#### 2 会用到的方法（同样先读这段）

**导向滤波借助原图结构。** 原图灰度作引导 g，粗透射率作输入 p；在局部窗口里用 `q=a*g+b` 近似输出，再平均重叠窗口的系数。

```text
a = cov(g, p) / (var(g) + epsilon)
b = mean(p) - a * mean(g)
q = mean(a) * g + mean(b)
```

所有均值、方差、协方差使用一致窗口。epsilon 与像素尺度有关，不能把 0-255 参数直接套到 0-1 浮点图上。

## C 问题的来龙去脉与发展过程

**从增强到复原。** 拉伸对比度可以改善观感，却没有显式估计雾的成因。散射模型把问题转化为估计 A 和 t；观测不足又要求额外假设。

**用图像统计补足信息。** He、Sun、Tang 在 CVPR 2009 的 DCP 工作中，用暗通道先验约束透射率。先验让问题可计算，也带来天空和亮物体的失败条件。[DCP 项目页](https://people.csail.mit.edu/kaiming/cvpr09/index.html)

**让估计贴合边缘。** 2010 年的导向滤波提出局部线性模型，可用于透射率细化。本项目组合两项方法，通过中间结果解释最终图像的变化。[导向滤波项目页](https://people.csail.mit.edu/kaiming/eccv10/index.html)
