# 神经网络：两层 MLP 的反向传播与整批训练

## 题目描述

给定一个两层全连接分类网络的初始参数和一批带标签的样本，请执行指定次数的**整批梯度下降**。每一步都要使用当前参数重新计算前向结果和 softmax 交叉熵梯度，再同时更新所有参数。最后，请输出更新后的参数、每个样本的预测类别，以及整批样本的平均交叉熵。

网络的输入维度为 $d$，隐藏层宽度为 $h$，类别数为 $c$。对输入向量 $x$，前向计算如下：

$\displaystyle u_j=\sum_{k=0}^{d-1}W^{(1)}_{j,k}x_k+b^{(1)}_j,\qquad a_j=\max(0,u_j).$

$\displaystyle z_t=\sum_{j=0}^{h-1}W^{(2)}_{t,j}a_j+b^{(2)}_t.$

$\displaystyle p_t=\frac{e^{z_t}}{\sum_{r=0}^{c-1}e^{z_r}}.$

真实标签为 $y$ 时，单样本交叉熵为 $-\log p_y$。记整批样本的平均交叉熵为 $E$。设 $\delta^{(2)}_t=p_t-[t=y]$，其中 $[t=y]$ 在 $t=y$ 时为 $1$，否则为 $0$。隐藏层的反向传播公式如下：

$\displaystyle \delta^{(1)}_{j}=[u_j>0]\sum_{t=0}^{c-1}W^{(2)}_{t,j}\delta^{(2)}_{t}.$

当 $u_j=0$ 时，规定 ReLU 的导数为 **0**。每一步都对全部 $n$ 个样本累加梯度，并除以 $n$。权重梯度的计算方式如下：

$\displaystyle \frac{\partial E}{\partial W^{(2)}_{t,j}}=\frac{1}{n}\sum_{i=1}^{n}\delta^{(2)}_{i,t}a_{i,j}.$

$\displaystyle \frac{\partial E}{\partial W^{(1)}_{j,k}}=\frac{1}{n}\sum_{i=1}^{n}\delta^{(1)}_{i,j}x_{i,k}.$

偏置梯度分别是对应 $\delta$ 的批量平均值。设学习率为 $\eta$，每一步执行 $\theta\leftarrow\theta-\eta\frac{\partial E}{\partial\theta}$。**同一步的全部梯度必须使用更新前的参数**，尤其在计算隐藏层梯度时，必须使用更新前的 $W^{(2)}$。训练时不打乱样本，也不使用动量、权重衰减或其他优化器。

为避免指数溢出，计算 softmax 和交叉熵时应先减去最大 logit。设 $m=\max_t z_t$，则可以使用 $e^{z_t-m}$ 计算概率，并用 $m+\log\sum_t e^{z_t-m}-z_y$ 计算单样本损失。

## 输入格式

第一行输入 $n,d,h,c,T,\eta$，依次表示样本数、输入维度、隐藏层宽度、类别数、更新步数和学习率。

其余各行按照下列顺序输入。

1. 接下来的 $h$ 行每行输入 $d$ 个实数，表示初始矩阵 $W^{(1)}$ 的一行。
2. 接下来的一行输入 $h$ 个实数，表示初始偏置 $b^{(1)}$。
3. 接下来的 $c$ 行每行输入 $h$ 个实数，表示初始矩阵 $W^{(2)}$ 的一行。
4. 接下来的一行输入 $c$ 个实数，表示初始偏置 $b^{(2)}$。
5. 最后的 $n$ 行每行输入 $d$ 个实数和一个整数标签 $y$，其中 $0\leq y<c$。

所有矩阵均按行优先顺序给出，类别从 $0$ 开始编号。

## 输出格式

首先，按输入时的相同顺序输出训练完成后的 $W^{(1)}$、$b^{(1)}$、$W^{(2)}$ 和 $b^{(2)}$，每部分占用与输入对应的行数。

然后，在一行中按输入样本的顺序输出 $n$ 个预测类别。预测时应使用**最终参数**；若最大 logit 并列，则取最小的类别下标。最后一行输出最终参数在这批样本上的平均交叉熵。

评测程序按空白分隔读取数值。对于每个实数，若输出值为 $a$，标准答案为 $b$，则需满足 $|a-b|\leq 10^{-5}+10^{-6}|b|$。预测类别必须完全一致，且不得输出额外内容。

## 样例

### 输入

```
1 1 1 2 1 0.1
1
0
0
1
0 0
1 0
```

### 输出

```
0.9268941421
-0.0731058579
0.0731058579
0.9268941421
0.0731058579 -0.0731058579
1
1.0263798023
```

样例中，网络对一个样本执行一次整批梯度下降，然后使用更新后的参数输出预测类别和平均交叉熵。

## 数据范围

数据满足 $1\leq n\leq 40$，$1\leq d\leq 784$，$1\leq h\leq 64$，$2\leq c\leq 10$，$1\leq T\leq 30$，$0<\eta\leq 0.2$。

所有输入数值均为有限值。输入向量、初始权重和初始偏置中，每个实数的绝对值均不超过 $100$。时间限制为 $6$ 秒，内存限制为 $256$ MiB。本题不需要 PyTorch 或 MNIST 数据文件。
