# AI5：神经网络

## A 问题是什么

怎样让程序从带标签样本中学习“输入到答案”的关系，而不是为每一种情况手写规则？神经网络把加权求和、非线性激活和可训练参数组合起来。Basic 用一个小型 MLP 识别手写数字，理解训练循环；Advance 实现小型 CNN，与 MLP 公平比较，观察图像结构、过拟合和错误样本。

| 阶段 | 工作量安排 | 难度 | 完成后的能力 |
| --- | --- | --- | --- |
| Basic | 一周内约 10-20 小时 | easy | 解释神经元与训练循环，训练一个 MNIST 小网络 |
| Advance | 完成 Basic 后再用六周 | medium | 理解卷积与参数共享，比较 MLP/CNN 并分析泛化 |

Basic 可用 CPU，不要求手推反向传播或训练大模型。

#### 2 本周用到的网络（先读这段）

**图像就是数字。** MNIST 一张灰度图为 28×28，可展平为 784 维向量。训练标签是人提供的正确数字，不能作为输入特征。

**神经元做加权求和。** 权重决定每个输入贡献，偏置平移得分；ReLU 把负值变成零。多层感知机（MLP）把这些运算叠起来，中间层称为隐藏层。

```text
[B,1,28,28] → 展平 [B,784] → Linear(784,64)
→ ReLU → Linear(64,10) → 十类 logits
```

**训练在改权重。** 交叉熵衡量预测与标签的差异，自动求导计算梯度，优化器据此更新参数。每批数据通常执行清零梯度、前向计算、求损失、反向传播、更新参数。

**logits 不是概率。** 分类时可直接取最大得分的索引。PyTorch 的 `CrossEntropyLoss` 接收 logits 和整数标签，训练前不要再手动加一层 softmax。

#### 3 代码任务：最小手写数字分类器

允许使用 PyTorch 的网络层、损失、优化器和自动求导。Basic 的重点是理解和组织流程。

1. 读取 MNIST 官方训练/测试集；可先固定抽取训练 5000 张、测试 1000 张，报告实际规模。
2. 搭建 `784→64→ReLU→10` 的 MLP，打印输入/输出形状。
3. 使用 batch size 64、学习率 0.001、Adam、3 个 epoch 作为起点，固定种子。
4. 每轮记录按样本数加权的平均训练损失；测试用 `model.eval()` 和 `torch.no_grad()`。
5. 打印测试准确率、样本数和至少 8 张预测；另找错误图，检查是否像相近数字。

```bash
python -m pip install -r requirements.txt
python train.py
```

`train.py` 已提供完整小型 MLP 入口，默认下载并使用完整 MNIST。第一次运行需要取得数据，后续可读缓存。抽样、验证集和按样本加权日志需要自行补充；不要把“读懂后直接运行”写成“从零实现自动求导”。

如果要比较学习率或结构，从官方训练集中留出开发集，最终测试集不用于挑设置。Basic 不设准确率门槛，损失也不要求每一步下降。

#### 4 用一个小例子核对

| x1 | x2 | h | z | 预测 | 是否正确 |
| ---: | ---: | ---: | ---: | ---: | --- |
| 0 | 0 | 0 | -0.5 | 0 | 是 |
| 0 | 1 | 0 | -0.5 | 0 | 是 |
| 1 | 0 | 0 | -0.5 | 0 | 是 |
| 1 | 1 | 1 | 1.5 | 1 | 是 |

这组权重是手工给定的，只演示前向计算。MNIST 的权重由训练得到；AND 例子本身线性可分，不能用它证明隐藏层比线性分类器更强，可另思考 XOR。
