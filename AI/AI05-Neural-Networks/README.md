# AI5：神经网络

## A 问题是什么

怎样让程序从带标签样本中学习“输入到答案”的关系，而不是为每一种情况手写规则？神经网络把加权求和、非线性激活和可训练参数组合起来。Basic 用一个小型 MLP 识别手写数字，理解训练循环；Advance 实现小型 CNN，与 MLP 公平比较，观察图像结构、过拟合和错误样本。

| 阶段 | 工作量安排 | 难度 | 完成后的能力 |
| --- | --- | --- | --- |
| Basic | 一周内约 10-20 小时 | easy | 解释神经元与训练循环，训练一个 MNIST 小网络 |
| Advance | 完成 Basic 后再用六周 | medium | 理解卷积与参数共享，比较 MLP/CNN 并分析泛化 |

Basic 可用 CPU，不要求手推反向传播或训练大模型。

#### 2 本周用到的网络（先读这段）

**图像就是数字。** MNIST 一张灰度图为 28×28，可展平为 784 维向量。训练标签是人提供的正确数字，不能作为输入特征。

**神经元做加权求和。** 权重决定每个输入贡献，偏置平移得分；ReLU 把负值变成零。多层感知机（MLP）把这些运算叠起来，中间层称为隐藏层。

```text
[B,1,28,28] → 展平 [B,784] → Linear(784,64)
→ ReLU → Linear(64,10) → 十类 logits
```

**训练在改权重。** 交叉熵衡量预测与标签的差异，自动求导计算梯度，优化器据此更新参数。每批数据通常执行清零梯度、前向计算、求损失、反向传播、更新参数。

**logits 不是概率。** 分类时可直接取最大得分的索引。PyTorch 的 `CrossEntropyLoss` 接收 logits 和整数标签，训练前不要再手动加一层 softmax。

#### 3 代码任务：最小手写数字分类器

允许使用 PyTorch 的网络层、损失、优化器和自动求导。Basic 的重点是理解和组织流程。

1. 读取 MNIST 官方训练/测试集；可先固定抽取训练 5000 张、测试 1000 张，报告实际规模。
2. 搭建 `784→64→ReLU→10` 的 MLP，打印输入/输出形状。
3. 使用 batch size 64、学习率 0.001、Adam、3 个 epoch 作为起点，固定种子。
4. 每轮记录按样本数加权的平均训练损失；测试用 `model.eval()` 和 `torch.no_grad()`。
5. 打印测试准确率、样本数和至少 8 张预测；另找错误图，检查是否像相近数字。

```bash
python -m pip install -r requirements.txt
python train.py
```

`train.py` 已提供完整小型 MLP 入口，默认下载并使用完整 MNIST。第一次运行需要取得数据，后续可读缓存。抽样、验证集和按样本加权日志需要自行补充；不要把“读懂后直接运行”写成“从零实现自动求导”。

如果要比较学习率或结构，从官方训练集中留出开发集，最终测试集不用于挑设置。Basic 不设准确率门槛，损失也不要求每一步下降。

#### 2 会用到的网络（同样先读这段）

**卷积核是共享的小探测器。** 一个 3×3 核在图上不同位置重复使用同组权重；训练会改变这些权重。一个通道可响应一种局部模式，但不能预先断言每个通道必然对应某个可命名概念。

**池化缩小空间尺寸。** 小窗口聚合减少后续计算，但也丢失部分精确位置。卷积、池化、激活承担不同作用。

建议 CNN：

```text
[B,1,28,28] → Conv 1→8, 3×3, padding=1 → ReLU → MaxPool 2
[B,8,14,14] → Conv 8→16, 3×3, padding=1 → ReLU → MaxPool 2
[B,16,7,7] → Flatten 784 → Linear 784→10
```

作为核对，上述 MLP 含 50,890 个参数，CNN 含 9,098 个参数（均含偏置）。两者参数量不同，结论应写成“这两个具体模型的比较”，不能归因于结构的唯一作用。

#### 3 方法实现与过程展示（G2-G4）

**实验清单：**

1. 官方训练集内固定划出开发集，官方测试集封存；所有模型用同一清单。
2. MLP 与 CNN 使用相同预处理、样本数、batch size、epoch 上限和优化器起点。
3. 开发集选择 checkpoint；若分别调参，候选数量和训练预算相同。
4. 打印每层形状与参数总量；训练日志保存配置、种子、epoch、损失和开发准确率。
5. 至少 3 个训练种子，固定划分，报告测试均值与波动、每轮耗时。

先用一小批数据检查模型能否拟合，再跑正式比较。若小批次损失一直不动，检查标签、梯度清零、学习率和损失输入，而不是先堆更多层。

| Basic MLP | 50,890 | 待测 | 待测 | 待测 |

## C 问题的来龙去脉与发展过程

**从单个计算单元到可学习表示。** 多层网络将简单运算组合成复杂映射，反向传播用链式法则计算参数梯度。现代框架负责求导，但使用者仍需理解损失、数据和更新顺序。[PyTorch 教程](https://docs.pytorch.org/tutorials/beginner/basics/quickstart_tutorial.html)

**针对图像设计连接。** 卷积利用局部结构和参数共享，MLP 与 CNN 因而以不同方式使用像素。本项目用小网络观察这种设计差别，而不是仅比较谁层数更多。

**让深网络更容易优化。** 2015 年发布的 ResNet 用残差连接研究深层网络的退化问题，说明结构设计也关系到优化难度。阅读时区分训练误差变大与过拟合，不把二者混为一谈。[ResNet 原论文](https://arxiv.org/abs/1512.03385)
