## A 问题是什么

给一段文字，计算机能"续写"下去吗？

这个能力你每天都在用：手机输入法猜你下一个要打的字，背后就是一个语言模型。今天的 ChatGPT 用上千亿个参数把这件事做到了极致，但你永远看不到它"想"的过程。而在神经网络出现之前，人类最早的语言模型简单到只用**数数**就能工作：统计"前 N-1 个字后面，每个字各出现过多少次"，然后按概率掷骰子。这个模型朴素得近乎可笑，却包含了现代语言模型的全部核心概念——概率分布、上下文、采样、评估、过拟合。

本项目的情景设定：**你要为一位作家打造一台"文风模仿机"**。给它读《红楼梦》，它就满口"红楼腔"；给它读鲁迅，它就变得冷峻锋利。没有神经网络，没有 GPU，只有一张你亲手统计出来的表。

这不是玩具项目，而是一次**科研探索的完整模拟**：你将亲手建立模型（任务一）→ 用它做出可观察的"预测"（任务二）→ 设计定量指标检验模型好坏并撞上过拟合（任务三）——这正是每一个机器学习研究者每天在做的事情的袖珍版。

最终你将交付：一个可运行的文本生成器 + 一次课堂展示。

### 三个核心思想

1. **马尔可夫假设**——"未来只依赖于现在，与更远的过去无关"。文本生成被简化为：给定前 N-1 个 token，下一个 token 的概率分布只由这 N-1 个 token 决定。这个假设很"天真"，却是统计语言模型的基石。
2. **语言模型 = 计数 + 概率**。语言模型本质上就是一张巨大的查找表："每个上下文后面跟着什么，各跟了多少次"。没有黑盒，没有玄学，只有可审计的统计——你将亲眼看到"模型"就是一个字典。
3. **N 的权衡（Bias–Variance Tradeoff）**。N 越大，生成越像原文（也越容易整段复述原文）；N 越小越有"创造性"（也越容易胡言乱语）。这是贯穿机器学习的核心矛盾，你将用实验亲手验证它。

### 任务一 构建 N-gram 模型

在 `src/model.py` 中完成 `build_ngram_model(tokens, n)`：用滑动窗口统计每个长度为 n-1 的上下文后面，各个 token 各出现了多少次。引导注释在代码里，动手前先读懂。

| 基础要求 | 说明 |
| --- | --- |
| 特殊符号 | 序列开头补 n-1 个 `<START>`，结尾补 1 个 `<END>` |
| 数据结构 | 字典：键为上下文（n-1 元组），值为各后续 token 的计数 |
| 边界情况 | `n=1` 时上下文是空元组 `()`，模型退化为词频统计，也应正确工作 |

可以先手工核对这个小例子（`check.py` 用的就是它）：

```text
tokens = ["我", "爱", "北京", "爱", "你"]，n = 2
补全后：<START> 我 爱 北京 爱 你 <END>
模型应当包含：
  ("<START>",) → {"我": 1}
  ("爱",)      → {"北京": 1, "你": 1}
  ("你",)      → {"<END>": 1}
```

完成后运行自测并"看见"你的模型：

```bash
python src/check.py                                  # 任务一应当通过
python src/main.py inspect --n 2 --context 的        # "的"字后面都跟着什么？
python src/main.py inspect --n 3                     # 模型整体统计
```

**思考**：

- 找一个续字高度集中的上下文和一个续字分散的上下文——这张表凭什么能"代表"一个作者的文风？
- 为什么开头要补 n-1 个 `<START>` 而不是 1 个？为什么必须有 `<END>`？（提示：没有 `<END>` 的模型，会在哪个环节暴露缺陷？）
- n=1 时模型退化成什么？你的代码需要为它特判吗？（好的实现不需要——想想为什么。）

### 任务二 生成文本

在 `src/generate.py` 中完成 `generate_text(model, n, length, seed)`：从 `<START>` 上下文出发，按计数加权随机采样下一个 token，滑动窗口前进，直到采出 `<END>` 或达到长度上限。


**思考**：

### 任务三 评估与平滑

在 `src/evaluate.py` 中完成 `token_probability(...)` 与 `calculate_perplexity(...)`。

"看起来像不像人话"是主观感受，科学需要**定量指标**。**困惑度（Perplexity）**是语言模型的标准评估指标，直觉含义："模型预测下一个 token 时，平均相当于在多少个等可能候选中犹豫"——**越低越好**：

$$\text{PPL} = \exp\left(-\frac{1}{M}\sum_{i=1}^{M} \ln P(w_i \mid \text{context}_i)\right)$$

像所有严肃的机器学习实验一样，把语料切成训练集（前 80%）和测试集（后 20%，**不能打乱**，文本是有序的）。你会立刻撞上问题：测试集里总有训练时没见过的上下文，概率为 0，$\ln 0 = -\infty$，困惑度直接爆炸——这正是任务二数据稀疏问题的量化体现。不要急着"修复"它，**先让爆炸发生**，它就是你的第一个重要实验现象。

解决办法是**平滑（Smoothing）**：给没见过的词也留一点概率质量。最经典的是 **Laplace（加一）平滑**：

$$P(w \mid \text{context}) = \frac{\text{count}(\text{context}, w) + 1}{\text{count}(\text{context}) + |V|}$$

其中 $|V|$ 是词汇表大小。

**实验**：`python src/main.py compare` 会同时输出无平滑与 Laplace 平滑的困惑度，并存入 `results/perplexity.csv`。据此绘制"N 值 vs 困惑度"曲线（X 轴 N=1,2,3,4，Y 轴困惑度；装了 matplotlib 会自动出图，没有就用 Excel/手绘均可）。

**思考**：

- 困惑度随 N 增大如何变化？再算一下**训练集**上的困惑度对比——一个单调下降，一个可能先降后升，**这就是过拟合**。和任务二的直观观察对上了吗？
- Laplace 平滑有什么缺点？（提示：$|V|$ 在分母里，中文按字切分时 $|V|$ 有几千，这对常见搭配的概率估计意味着什么？）
- 为什么不能把语料打乱再切分测试集？打乱了会发生什么更隐蔽的问题（信息泄漏）？

**基础部分阅读材料**（帮助回答上述问题）：Shannon 1948《通信的数学理论》的 §3 "The Series of Approximations to English"（很短，且与本项目任务二一一对应，[原文 PDF](https://people.math.harvard.edu/~ctm/home/text/others/shannon/entropy/entropy.pdf)）。读后思考：香农手工做了什么实验？和你的代码有何对应？

### OJ 提交（Basic 验收）

**输入格式**：第一行 `N Q`（1 ≤ N ≤ 4）；第二行为训练语料，若干 token 以单个空格分隔（中英文混合，可能为空行）；随后 Q 行每行一个查询：

- `COUNT c1 … c_{N-1} w`：输出语料（开头补 N-1 个 `<START>`、结尾补 1 个 `<END>` 之后）中该上下文后紧跟 `w` 的次数；N=1 时格式为 `COUNT w`。未出现的上下文或词输出 0；

**采样规则（钉死，保证可复现）**：`rng = random.Random(seed)`；每步候选 = 该上下文全部后继按 Python 默认字符串序排列，权重 = 整数计数，抽取方式恰好为 `rng.choices(candidates, weights=counts, k=1)[0]`。

**样例输入**：

```text
2 6
我 爱 北京 爱 你
COUNT 爱 北京
COUNT 爱 你
COUNT <START> 我
COUNT 你 <END>
COUNT 我 你
COUNT 北京 爱
```

**样例输出**：

```text
1
1
1
1
0
1
```

### C1 文风鉴别器：你的模型其实是个分类器

用两份风格迥异的语料分别训练模型，给定一段"神秘文本"，哪个模型给它的困惑度更低，它就"更像谁写的"——你已经无意间造了一个**文本分类器**。语料赛道（见基础部分）让可玩的组合变多了：中文小说可以选《红楼梦》vs《骆驼祥子》（古典 vs 京味白话），英文可以选莎士比亚 vs 泰戈尔（格律诗 vs 散文诗）。

**实验步骤**：

1. 选定一对语料 A、B，各自按前 80% / 后 20% 切分（不打乱），用前 80% 各训一个 N=3、Laplace 平滑的模型；
2. 从两份语料的**后 20%** 里各截取 5 段约 200 token 的段落，共 10 个测试样本，记下每段的真实出处（这对模型保密）；
3. 每段分别交给两个模型算困惑度，PPL 低的一方判为作者，统计 10 题的准确率；
4. 把 N 换成 1、2、4 重复以上步骤，填一张"N vs 鉴别准确率"的表；
5. 加码挑战：混入第三者的文字（比如用《红楼梦》模型 + 《骆驼祥子》模型鉴别一段鲁迅），或者混入你自己模仿的文字，看看会判给谁。

**需要回答**：N 取多大时鉴别最准？为什么 N 太大反而失灵（回到数据稀疏去想）？同文体的两份语料（如两部小说）比跨文体（小说 vs 诗歌）更难鉴别吗？

**延伸**：这就是垃圾邮件过滤、作者考证的最小原型——《红楼梦》后四十回是否出自高鹗，真有学者用这类统计风格学（stylometry）方法研究过，有兴趣可以去查查。

### C2 复现香农 1951：测量中文的"熵"

香农用"猜下一个字母"的游戏测量过英文的熵。你来做一个中文版，并且让真人和你的模型正面交锋。

**实验步骤**：

1. 选一段约 200 字、受试者（你的同学）没读过的文本（赛道任选）；
2. 逐位置遮盖：每次只展示已确定的前文，让受试者猜下一个字，记录每个位置"猜了几次才猜中"；
3. 统计各位置猜测次数的分布，按香农论文中的方法换算成每字信息量的估计（论文里有现成的换算表）；
4. 用你的 N-gram 模型（N=2 和 N=3）对**同一段**文字计算交叉熵（把困惑度取 log₂ 即得"比特/字"）；
5. 对比人和模型的数字，并找出人完胜模型的具体位置。

**需要回答**：人的猜测和模型的猜测，谁更接近真实文本分布？在那些人类轻松猜对、模型却卡壳的位置上，人到底用了什么模型永远看不见的信息？

**阅读**：[Shannon 1951, *Prediction and Entropy of Printed English*](https://www.princeton.edu/~wbialek/rome/refs/shannon_51.pdf)。

### C3 更聪明的平滑：从 Laplace 到插值

Laplace 加一太粗糙：它给所有没见过的上下文均匀地分概率。更合理的想法是——高阶模型没见过的上下文，用低阶模型的概率兜底。

**实验步骤**：

1. 先跑基线：N=3、Laplace 平滑，记录测试集困惑度；
2. 实现**线性插值**（Jelinek-Mercer）：P(w | 二元上下文) = λ·P₃(w | 二元上下文) + (1-λ)·P₂(w | 一元上下文)，其中 P₂ 可以再用同样方式插值到 P₁；
3. 在 λ ∈ {0.1, 0.3, 0.5, 0.7, 0.9} 的网格上各算一次测试困惑度，画出"λ vs PPL"曲线，找到最优 λ；
4. 只用一半训练语料重跑一次：最优 λ 移动了吗？
5. 与 Laplace 基线对比，困惑度降了多少？

**需要回答**：为什么"按低阶概率兜底"比"均匀兜底"合理？λ 的直觉含义是什么，为什么语料越少它应当越小？

**延伸**：意犹未尽就去读懂 **Kneser-Ney 平滑**的思想（不必实现）——统计语言模型时代公认最优雅的技巧，核心直觉一句话："没见过"的词该分多少概率，取决于它在多少种**不同上下文**里出现过。

**阅读**：Jurafsky & Martin《Speech and Language Processing》第三版第 3 章（官方免费公开，[PDF](https://web.stanford.edu/~jurafsky/slp3/3.pdf)）。

### C4 从查表到神经网络：N-gram 之后发生了什么？

N-gram 的根本困境是"只认得逐字见过的上下文"。神经网络如何绕开它？这个方向不要求完整实现，但鼓励你顺着下面的路径走一段，能走多远走多远：

1. 读 Karpathy 的著名博文 [*The Unreasonable Effectiveness of Recurrent Neural Networks*](https://karpathy.github.io/2015/05/21/rnn-effectiveness/)（2015）——看字符级神经网络生成的"假莎士比亚"，和你在 `shakespeare.txt` 语料上的 N=4 输出逐段对比：各犯的错一样吗？
2. 学有余力者，跟随 Karpathy 的 **makemore** 教程（[GitHub 仓库](https://github.com/karpathy/makemore) + 配套视频），从零手写一个微型神经语言模型（允许使用 PyTorch，仅本方向例外）；
3. 无论走到哪一步，最后回答：神经模型用"连续向量"表示上下文，这一下解决了 N-gram 的哪个致命问题？又引入了什么新代价？

## F 问题的来龙去脉与发展过程

**马尔可夫链的诞生（1913）**。俄国数学家安德烈·马尔可夫为了反驳"大数定律只适用于独立事件"的观点，拿普希金的长诗《叶甫盖尼·奥涅金》做实验：他把两万个字母按元音/辅音分类，手算"下一个字母是元音"的概率如何依赖于前一个字母——证明了**相依随机变量**同样存在稳定的统计规律。这就是马尔可夫链的起点：一次纯粹的文本统计实验。

**信息论与语言的统计模型（1948–1951）**。香农在《通信的数学理论》中提出：语言可以建模为"根据前 N-1 个符号预测下一个符号"的概率分布。书中 §3 "The Series of Approximations to English" 手工构造了从 0 阶（完全随机）到 3 阶（trigram 单词）的一系列"假英文"——**你在本项目任务二中做的事情，就是这一节的计算机复现**。1951 年他又用"猜下一个字母"的游戏测量了英文的熵，这个游戏今天叫语言模型评估。[Shannon 1948](https://people.math.harvard.edu/~ctm/home/text/others/shannon/entropy/entropy.pdf)、[Shannon 1951](https://www.princeton.edu/~wbialek/rome/refs/shannon_51.pdf)（进阶部分 C2 会带你亲手复现 1951 年的实验）。

**N-gram 的黄金时代（1980s–2010s）**。从 IBM 的语音识别到 Google 的机器翻译，N-gram + 平滑（Kneser-Ney 等）统治了语言建模三十年。2006 年 Google 发布了从万亿词料统计的 N-gram 数据集——"大数据 + 简单模型"一度是行业标准答案。

**被取代，但没有消失（2017–）**。神经语言模型与 Transformer 用连续向量表示上下文，摆脱了"精确匹配上下文"的稀疏困境，困惑度大幅超越 N-gram。但核心框架未变：依然是"给定上下文，预测下一个 token 的概率分布"，依然用困惑度评估，采样时依然要调 temperature。你在任务三撞见的每一个问题（稀疏、平滑、过拟合），都以更隐蔽的形式存在于今天最大的模型里——进阶部分 C4 会带你亲眼看见这场接力。
